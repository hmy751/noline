# Noline Archive

이 디렉터리는 현재 정책으로 바로 읽기에는 위험하거나 오래된 자료를 보존한다. 삭제하지 않고 history/evidence로 남기는 것이 목적이다.

## 현재 하위 영역

| 위치 | 역할 |
| --- | --- |
| `implementation/` | 오래된 v3 구현 추적표와 테스트 시나리오 |
| `references/` | 오래된 PRD, wireframe, 기술 참고 자료 |
| 기타 Markdown 파일 | 과거 구현 가이드, rollout history, legacy examples |

## 사용 원칙

- active guide와 충돌하면 active guide와 현재 코드를 우선한다.
- archive 자료를 다시 현재 정책으로 올릴 때는 가장 작은 owner 문서로 요약하고, 필요하면 `decisions/`에 이유를 남긴다.
- archive 안의 완료/미완료 표기는 현재 상태가 아니라 당시 기록으로 읽는다.
