## 🎨 UI 컴포넌트 가이드

### 타이포그래피 (React Native용)

> 📖 상세 스펙은 `DESIGN_SPECS.md` 참고

**텍스트 스타일 클래스:**

- `text-display-large` (32px/Bold) - 앱 타이틀, 히어로 텍스트
- `text-display-medium` (24px/Semibold) - 큰 금액, 통계 숫자
- `text-title-large` (20px/Semibold) - 섹션 제목
- `text-title-medium` (16px/Semibold) - 카드 제목, 일정 제목
- `text-body-large` (16px/Regular) - 강조 본문
- `text-body` (14px/Regular) - 일반 본문, 설명
- `text-label` (12px/Regular) - 라벨, 시간, 부가 정보
- `text-label-small` (10px/Medium) - 배지, 태그

**화면별 사용 예시:**

**홈 화면:**

- "Project noline" → `text-display-large`
- "EUR 156.50" → `text-display-medium text-primary`
- "📅 오늘의 일정" → `text-title-large`
- "에펠탑 방문" → `text-title-medium`
- "📍 에펠탑" → `text-body text-muted-foreground`

### 색상 사용

- **Primary (오렌지)**: 주요 액션 버튼, 선택된 상태
- **Success (초록)**: 온라인 상태, 동기화 완료
- **Warning (노랑)**: 동기화 중
- **Error (빨강)**: 오프라인, 오류
- **Muted (회색)**: 보조 정보, 비활성

### 아이콘 의미

- 🏠 홈
- 📅 일정/날짜

- 📍 위치
- 🕐 시간

- ✓ 동기화 완료
- ⚠️ 동기화 필요
