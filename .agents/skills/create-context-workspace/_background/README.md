# Work 생성 수행의 형성 자료

이 자료는 prototype의 형성 맥락·당시 선택을 보존한다. 설치 대상의 현재 Work 갱신·생성·전환은 기존 계약을 유지하도록 적응했다. [이번 적응과 남은 연결](records/2026-10-30-existing-work-contract-adaptation.md)을 먼저 구별하며, 아래 당시 Main 직접 기록·수동 demo 설명으로 현재 운영 계약을 바꾸지 않는다.

요청된 독립 목표를 새 Work로 구성하는 [실행 본문](../SKILL.md)이 왜 생성 계약을 참조하고 수동 demo와 실제 runtime을 구별하는지 설명한다. 현재 생성·전환 기준은 [Work 계약](../../../../context/work/workspaces/CREATE-AND-TRANSITION.md)에 있다. 일상 실행은 그 계약과 스킬 본문을 사용한다.

- [형성 맥락](context.md): 기존 생성 책임을 유지한 이유, 내용 계약과 수행 수단의 분리, 잠정 이름과 운영 전환의 경계.
- [근거](evidence.md): 사용자 요청과 기존 원형·외부 고정판에서 실제로 이어받은 관계와 한계.
- [적용 기록](records/2026-10-26-prototype-integration.md): 수동 demo에 옮긴 범위와 실제 생성·전환 시험의 구별.

이 스킬의 의미·구성을 바꿀 때는 [스킬 본문 관리 원칙](../../SKILLS-CONTENT-POLICY.md)을 함께 읽는다. Work 내용 구조에 새 형성 자료 층을 추가하는 계약은 아니다.
