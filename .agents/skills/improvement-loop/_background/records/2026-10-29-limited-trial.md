# 선택한 한정 시도를 기존 작업과 종료 정리에 연결한다

[실행 본문](../../SKILL.md)과 [적용 사례](../../references/application.md)의 한정 시도 보완 기록이다.

독립 개선 리뷰는 Personal의 후보 보존과 다음 실제 작업의 실행 사이에 연결을 더 구체화할 것을 권했다. 기존 방식이 이미 실패했다는 판정은 아니며, 함께 선택한 시도를 바로 실행하는 목적을 강화하는 제안이다.

사용자는 “1번부터 좀 더 구체적으로 설명해봐 기존 구조에서 어디에 어떻게 연결하고 끝나면 어떻게 정리할지”라고 요청했다. Main은 Personal의 기존 주제에 선택·이유를 남기고, 특정 다음 작업의 기존 재개 본문에 시도 범위·행동을 연결하며, 종료 때 임시 지시를 정리하고 실제 경험을 같은 주제에 남기는 안을 설명했다. 그 직후 사용자는 “그래”라고 수용했다. 이 수용은 이 운영 방식의 prototype 반영이며 사례 속 ‘비교 후 질문하기’를 실제 개인 기준으로 채택한 것은 아니다.

현재 대화에서 곧바로 할 수 있으면 수행하고, 다음 실행 작업이 미정이면 Personal에 보존하되 연결 완료라고 하지 않는다. Work를 억지로 만들거나 별도 시도 관리층을 두지 않는다. 종료 책임도 실제 수행자가 읽는 지점에 남겨 다음 루프를 기다리지 않고 정리할 수 있게 한다. 미사용·효과 미확인은 실패나 성공으로 바꾸지 않으며 지속 채택은 별도 선택이다.

스킬은 실행 연결·종료 책임을, USAGE는 선택된 시도의 읽기를, Personal 관리는 선택·연결·사용 결과의 보존을 맡는다. 적용 사례는 이 책임을 가정 장면으로 펼친다. 기존 역사적 경험 주제와 인증 demo의 작업 지시는 바꾸지 않았다.

확인은 Main의 본문·읽기 경로 대조와 viewer 검사다. 실제 후속 세션의 시도 수행·자동 회수·사용 효과를 시험한 것이 아니다. 같은 목적에서 수행 수단을 비교하는 두 번째 개선안은 이번에 채택하거나 반영하지 않았다.
