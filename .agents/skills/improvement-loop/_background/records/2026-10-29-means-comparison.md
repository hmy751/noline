# 같은 목적에서 개선 수단을 비교하는 사례를 보완한다

[스킬](../../SKILL.md)과 [적용 사례](../../references/application.md)의 두 번째 개선안 반영 기록이다.

기존 독립 개선 리뷰는 문서·협업 중심 사례만으로는 도구·환경까지 포함하는 개선 판단이 충분히 드러나지 않을 수 있다고 보았다. Main은 좋은 편집 경험은 유지하고 가상의 중복 문서 통합 예시를 대화 전체 확인의 수행 수단 비교로 바꾸는 안을 설명했다.

사용자는 “그래 설명해봐”라고 요청했고, Main은 현행 유지·범위/메시지 구별 설명 보완·읽기 전용 추출 도구의 한정 시도를 실제 확인한 조건에 따라 비교하자고 설명했다. 설명 끝에서 추천 범위를 ‘이 비교 사례의 보완까지’로 한정하고 도구 제작·설치 결정과 구별했으며, 사용자는 “그래”라고 수용했다.

같은 목적에서 실제 수행 차이와 비용을 비교하는 판단만 스킬 본체에 짧게 연결하고, 조건별 대비는 적용 사례가 맡는다. 매 후보에 세 대안을 채우는 규칙이나 도구 제안 의무는 만들지 않았다. 대화 전체 확인의 실제 절차는 conversation.md가 계속 소유한다.

확인된 반복 비용·누락·효과를 새로 주장하지 않는다. 원문 준비를 도구에 맡기는 경우에도 전체 읽기·개선 판단은 Main이 맡고, 실제 도구 선택은 별도 사용자 선택이다. 이번에는 스킬 설명과 사례만 바꾸며 Personal 역사적 경험·제품 코드·도구·운영 설치를 수정하지 않았다.
