# 네 묶음 합의를 실행 파일로 펼친 기록

2026-10-28. [실행 본문](../../SKILL.md)의 프로토타입 구체화 기록이다.

기존 development에 루프 전체를 더하면 일상 수행과 사용자 요청 회고가 섞이므로 별도 learning-loop로 두고 호출 관계만 연결했다. 대화 원문과 효과 판단은 해당 상황에서 읽는 상세다. Personal은 경험 관리의 정본을 가지며, 길잡이·주제별 설명·아직 묶지 않은 기록으로 실제 내용을 찾게 했다. 새 전역 설치·자동 hook·독립 리뷰어를 추가하지 않았다.

정확한 파일명은 Main이 이번 요청의 구현 선택으로 정했다. 주제 전체를 미리 분류하는 대형 구조보다 현재 근거가 있는 세 주제와 한 미분류 질문을 넣었다. 파일 배치의 우월성·후보의 실제 효용·일반 채택은 검증하지 않았다. 표본 경험이 지금 Noline demo에서 새로 발생한 사건이 아님을 명시했다.

현재 로컬 세션 파일을 식별하고 메시지 형식을 확인해 원문 접근 예를 구체화했다. 실행안 작성 중 세션 전체 검토를 수행한 것은 아니다. 실제 루프 요청에서는 원문 범위와 훑기를 수행해야 한다. 원문이 부족하면 한정 개선을 계속할 수 있지만 전체 대화 확인은 미완료로 남긴다.

[적용 사례의 현재 위치](../../references/application.md)이 실제 읽는 순서와 대표 장면, 남은 설치·관찰 경계를 설명한다. 이번 파일판의 점검은 Main의 대조이며 앞선 독립 리뷰가 이 판본을 검토한 결과로 표현하지 않는다.
