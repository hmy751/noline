# 사용과 도움·부담을 구별해 다음 선택을 한다

[improvement-loop](../SKILL.md)에서 이전 반영의 실제 경험을 판단할 때 읽는다. 매 대화의 평가나 만족도 질문을 추가하는 절차가 아니다.

이전 주제에서 무엇을 바꾸려 했는지, 채택·한정 시도 범위와 실제 반영 대상을 복원한다. 이번 대화·산출물·사용자 평가에서 그 방법을 쓸 장면과 실제 행동을 대조한다. 관련 기록이 있는 다른 세션도 필요한 만큼 확인할 수 있지만 접근하지 못한 사용을 있었다고 간주하지 않는다.

| 확인된 상태 | 다음 판단 |
| --- | --- |
| 관련 사용 장면 없음 | 효과를 판단하지 않는다. 계속 확인할 과제를 억지로 만들지 않는다. |
| 써야 할 장면은 있으나 읽기·사용이 확인되지 않음 | 찾는 경로·상황 적합성·지시 이해·수행 중 어디에 공백이 있는지 본다. 방법 자체가 무효하다고 확정하지 않는다. |
| 읽었으나 행동에는 충분히 나타나지 않음 | 누락 원인과 기존 지침·입력을 대조한다. 새 문구 추가를 자동 해법으로 삼지 않는다. |
| 적용했으나 이득이 불분명함 | 다른 조건의 영향·근거 한계와 유지 부담을 함께 본다. 부담이 작고 기대 이유가 남으면 유지할 수 있고, 부담이 뚜렷하거나 기존 방식이 충분하면 간소화·조건 축소·철회를 제안할 수 있다. |
| 도움과 부담이 조건별로 다름 | 유효한 조건을 살리고 과도한 적용을 좁히거나 대안을 비교한다. 일부 이득을 전체 우세로 확대하지 않는다. |
| 실제 문제·부담이 확인됨 | 변화와 문제의 관계를 대조해 수정·되돌림·대체를 제안한다. 명확한 문제는 반복될 때까지 기다리지 않는다. |

읽음·적용·도움은 각각 다른 사실이다. 사용자의 침묵이나 질문 감소를 만족의 근거로 만들지 않는다. 상관을 단독 인과로 바꾸지 않는다. 자료로 풀리지 않는 중요한 선택만 짧게 질문한다.

## 비교가 다음 선택을 바꿀 때

비교 결과가 유지·수정·철회 선택을 바꿀 수 있고 비용에 맞는 가치가 있을 때 한정 비교를 제안한다. 관련 대표 요청·자료에서 대안의 조건과 결과를 대조한다. 긴 대화 전체 재실행·매 변경 비교·무기한 반복은 기본이 아니다. 결정적이지 않으면 불확실성을 남긴다.

## 원래 경험과 실제 대상에 결과를 잇는다

확인한 사실·모르는 부분·추천과 이유를 사용자에게 보여주고 선택된 범위를 반영한다. 원래 Personal 주제의 경험·현재 이해·열린 후보와 실제 대상 연결을 갱신한다. 실제 기준 변경은 그 정본이 맡으며, 모든 효과를 별도 Work에 등록하지 않는다.
