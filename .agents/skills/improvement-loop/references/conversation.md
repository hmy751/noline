# 현재 세션 대화의 범위와 원문을 확인한다

[improvement-loop](../SKILL.md)가 대화 전체를 훑을 때 쓰는 입력 절차다. Main의 맥락을 새 세션으로 넘기거나 별도 로그 시스템을 설치하지 않는다.

## 현재 문맥과 원문 접근을 연결한다

1. 현재 세션의 식별자·시작과 이번 요청까지의 범위를 확인한다. 사용자와 AI의 실제 발화 순서가 보이는 현재 문맥을 사용하되, 압축 요약·인용된 이전 대화·도구 결과를 실제 새 발화와 구별한다.
2. 앞부분이 압축됐거나 빠졌으면 현재 host의 접근 가능한 세션 원문·기존 대화 로거·사용자가 제공한 원문에서 **같은 세션**을 찾는다. 이름·수정 시각만으로 가장 최근 파일을 고르지 않는다. 전체 archive나 다른 프로젝트의 대화를 기본으로 모으지 않는다.
3. 사용자·AI 발화를 시작부터 현재 요청까지 순서대로 읽는다. 길면 연속 구간으로 나누어 훑고 각 구간의 경계와 남은 구간을 이어간다. 키워드 검색은 위치 찾기용이지 전체 훑기의 대체가 아니다. 주장 확인에 필요한 도구 입출력·산출물은 해당 장면에서 추가로 읽는다.
4. 맥락에 이미 유효하게 읽은 구간은 재사용할 수 있다. 한정된 출력이 잘리면 남은 구간을 이어 읽는다. 읽은 구간과 제공되지 않은 구간을 섞어 전체 확인으로 표시하지 않는다.

매 실행마다 열람 장부를 영구 저장할 필요는 없다. 후보 설명에서 사용한 원문 위치와 중요한 한계를 재접근할 수 있으면 된다. 저장할 근거는 관련 경험의 판단에 필요한 발췌로 줄인다.

## 로컬 Codex의 세션 파일을 사용하는 경우

현재 host가 `CODEX_THREAD_ID`와 로컬 세션 파일을 제공하면 `~/.codex/sessions/` 아래 그 식별자가 들어간 `rollout-*.jsonl` 파일을 대조한다. `session_meta`의 `payload.id` 또는 `session_id`와 `cwd`를 확인해 대상을 확정한다. 경로 패턴은 확인한 환경의 접근 예이며 모든 host에 대한 계약이 아니다.

실제 파일이 다음 메시지 구조를 사용하는지 먼저 확인한다. 확인한 판본에서는 `response_item` 중 `payload.type = message`의 `role = user | assistant`, `content`의 `input_text | output_text`가 발화를 담았다. 원본 줄 번호·순서를 유지하며 읽고, `event_msg`에 중복된 같은 발화를 다시 세지 않는다. system/developer 지침·tool 결과·reasoning을 사용자의 발화로 합치지 않는다. 사용자 메시지 안에 주입된 설정·이전 대화가 있으면 실제 사용자 발화와 구별한다. 도구 호출·출력은 필요한 사건에서 원래 줄로 돌아가 확인한다.

`compacted`의 replacement history는 요약·재구성일 수 있다. 같은 파일에 압축 전 원문이 남았는지 확인하고 원문을 우선한다. 파일이 있다는 사실이나 첫·끝 발화만 맞는다는 사실은 중간 원문과 이전 이관 구간의 완전성을 보장하지 않는다. fork·재개로 이전 세션을 참조하면 그 연결과 필요한 이전 원문을 확인한다. 다른 host에서는 해당 환경이 제공하는 실제 원문 접근 방법으로 같은 의미를 충족한다.

이 접근 예의 확인판과 당시 확인 범위는 [형성 기록](../_background/records/2026-10-28-structure.md#원문-접근-예의-확인판)에 있다. 환경별 예가 있다는 사실로 현재 세션 원문의 완전성이나 전체 열람을 확인했다고 보지 않는다.

## 원문을 확보하지 못한 경우

어느 구간이 요약뿐인지, 어떤 결론에 영향을 주는지 짧게 밝힌다. 가능한 원문 복구를 먼저 수행하고, 선택을 바꿀 중요한 부분만 사용자에게 확인한다. 요약으로만 복원한 의도·인과는 확정하지 않는다.

부분 근거로도 판단할 수 있는 개선은 계속 제시·반영하되 **전체 대화 검토는 미완료**로 남긴다. 단순히 ‘일부만 봤다’고 고지하는 것으로 전체 훑기 요구를 완료 처리하지 않는다. 접근 경로 확인은 다음 실제 host 적용에서 해소할 과제이며 무관한 전체 로그 수집의 이유가 아니다.
