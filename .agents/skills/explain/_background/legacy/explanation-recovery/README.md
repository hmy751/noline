# 설명 복구의 형성 자료

2026-10-23에 실행 책임을 [explain](../../../SKILL.md)으로 통합했다. 이 묶음은 이전 복구 스킬의 선택 이유를 보존하며 현재 실행 지침이 아니다. [통합 이유](../../README.md)와 [통합 직전 보류 후보](records/2026-10-23-before-explain.txt)를 구별해 읽는다. 아래 ‘현재’는 통합 전 상태를 설명한다.

이 묶음은 앞선 AI 설명의 실제 뜻을 복구하는 책임과, 작은 답에서 시작하면서 오류·이의 제기도 다루게 된 이유를 보존한다. 의도 확인·과거 선택 재검토 때 관련 자료를 선택해서 읽는다.

현재 SKILL.md는04-02의 보류한 수정안이다. 이 배경은 **그 수정 전 스킬의 형성 의도와 보강 경위**이며 최신 후보의 채택 근거로 읽지 않는다.
