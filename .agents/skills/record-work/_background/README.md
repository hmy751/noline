# Record Work의 형성 자료

[실행 본문](../SKILL.md)은 현재 호출·배정·기록·반환을 소유한다. 이 층은 역할과 구현을 다시 판단할 때 읽는다.

- 필요해진 이유와 책임 배치: [형성 맥락](context.md).
- 리뷰의 추천이 다음 세션의 우선순위로 읽힌 경위와 확인 문장만 채택한 이유는 [첫 행동 비교](context.md#기록에서-다음-행동의-우선순위를-다시-보는-이유)에 있다.
- 사용자 선택과 미채택 대안의 근거: [최소 원문](evidence.md).
- prototype 반영과 확인 경계: [도입 기록](records/2026-10-30-record-work.md).
- 재개 안내를 기록 범위에 포함한 이유와 생성 담당과의 연결: [재개 안내 연결](records/2026-11-04-recovery-guide.md).

사용할 때 이 자료 전체를 읽을 필요는 없다. 기록 결과는 대상 Work가 소유하며 여기에 누적하지 않는다.

위 prototype 선택을 Reference에 옮긴 범위는 [Reference 재개 안내 적용](records/2026-11-04-reference-recovery-adoption.md)에서 확인한다.
