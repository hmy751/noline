# 직전 반영 이후에서 필요한 앞선 맥락으로 확장한다

Main과 기록 담당자는 [공통 원문 접근](../../shared/conversation-source.md)으로 같은 Main 대화의 원문을 식별한다. Main은 자신의 대화 식별자를 명시하며 서브가 자기 대화의 식별자로 대신 찾지 않게 한다. 로그 경로·원본 줄 또는 메시지 식별자로 입력의 시작과 이번 끝을 구별한다. 역할 배정의 요약은 원문을 대신하지 않는다.

기본 입력은 마지막으로 반영한 지점 이후부터 이번 호출의 끝까지다. 이전 미반영 내용이 있으면 그 구간도 포함한다. 최초 호출이거나 마지막 반영 지점이 불명확하면 기존 기록·현재 문서와 관련 원문을 대조해 범위를 넓힌다. 필요한 근거 없이 최신 구간만 읽고 전체가 기록됐다고 추정하지 않는다.

정정이 무엇을 바꾸는지, 제안이 채택됐는지, 선택의 이유가 무엇인지 이해하려면 앞선 대화를 자유롭게 찾아 읽는다. 단순 검색 결과만으로 입력 구간 전체를 확인한 것으로 표시하지 않는다. 이미 유효하게 읽은 맥락은 재사용하되 새 사실이나 충돌이 있으면 다시 대조한다.

이번 호출의 끝은 고정한다. 기록 중 새로 도착한 발화는 후속 호출에서 처리하고 늦은 결과도 원래 Work와 입력 구간에 귀속한다. 같은 대화 안에서 Work가 전환됐으면 발화의 실제 대상과 배정을 구별한다.

원문에 없는 subagent 반환·실행 결과는 Main이 정확한 접근점을 연결한다. 부족한 입력은 필요한 부분만 요청하고, 현재 확인 가능한 내용은 기록할 수 있다. 읽은 범위·반영한 범위·미반영 위치를 반환하며 원문 공백이나 부분 실패를 완료로 넘기지 않는다. 다음 호출은 그 반환과 실제 문서에서 이어간다.
