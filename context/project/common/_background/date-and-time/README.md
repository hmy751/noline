# 날짜·시각 기준의 형성 자료

[날짜와 시각](../../date-and-time.md)의 필드 의미와 호환·책임 배치를 만든 목적, 선택 이유와 재검토 조건을 보존한다. 현재 적용은 본문에서 찾고, 의미를 바꾸거나 과거 선택을 재검토할 때 필요한 자료를 읽는다.

- [형성 맥락](context.md): Expense 날짜 정규화를 저장 전으로 옮긴 이유, UTC 저장과 도시 시간대를 함께 유지한 선택·비용.
- [형성 근거](evidence.md): 사용자 발췌와 당시 선택 범위, 현재 코드가 보장하는 범위를 바로잡은 관찰.
