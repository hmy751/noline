# Noline의 지속 제품 맥락

이 폴더는 제품·데이터·시스템을 어떤 의미로 이해하고 어떤 핵심 관계를 지켜야 하는지 설명한다. 기술적인 내용도 제품 의미나 핵심 제약이면 포함하며, 추상적인 설명만 두는 층은 아니다. 관련 작업의 구체적인 적용·변경 기준은 [guidance](../guidance/README.md)가 맡는다.

현재 본문은 [제품 의미와 공통 기준](product.md)이다. 새 Work의 제품 목적·사용자 장면과 보존할 데이터 관계를 판단할 때 읽는다. 현재 지원·구현 차이가 판단에 필요하면 [current](../current/README.md)의 관련 본문을 추가한다. 모든 작업이 이 폴더 전체를 읽을 필요는 없다.

제품 의미를 바꾸는 책임자가 [관리 계약](../MAINTENANCE.md)에 따라 관련 Owner와 대조해 갱신한다. 특정 Workspace의 목표나 검증 이력은 여기에 올리지 않는다. 새 본문의 범위와 분리는 [구성 기준](../REFERENCE/composition.md)을 따른다.
