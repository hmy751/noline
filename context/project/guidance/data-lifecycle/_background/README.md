# 저장·동기화·정리의 형성 자료

[본문](../INDEX.md)의 보존 계약과 책임 구분을 이해하거나 변경할 때 읽는 자료다. 현재 적용은 본문이 맡고, 여기서는 의도·당시 선택·관찰을 구별한다. 과거 문서의 구현 예시나 완료 표시는 현재 보장이 아니다.

- 비활성화와 실제 삭제를 왜 나눴는지, 저장 비용을 왜 받아들였는지: [형성 맥락](context.md)
- 과거 결정과 후속 보완에서 어떤 뜻을 유지하고 어떤 보장을 정정했는지: [선택 근거와 관찰](evidence.md)

옛 제품 문서로 돌아가지 않고 선택 이유를 판단할 수 있도록 필요한 근거를 이곳에 선별했다. 전체 조사·테스트 실행의 이력은 해당 Work에서 관리한다.
