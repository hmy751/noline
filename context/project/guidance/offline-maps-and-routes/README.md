# 오프라인 지도·경로

여행에 필요한 지도 파일과 이동 경로를 준비하고, 연결이 끊겼을 때 무엇을 표시할 수 있는지 관리하는 주제다. [시작 본문](INDEX.md)은 데이터 입수·지도·경로의 서로 다른 완료와 화면 선택을 설명한다. pack 다운로드·정리는 [지도 파일](map-packs.md), 일정 변경·경로 재사용·표시는 [저장 경로](routes.md)에서 이어 읽는다.

현재 적용과 구현 차이는 위 본문이 소유한다. Mapbox·도시 공유·경로 사전 계산을 선택한 목적과 비용을 재검토할 때는 [형성 자료](_background/README.md)를 읽는다. 필요한 이유를 Project 안에 선별해 보존했으며 옛 구현 문서는 일반 읽기 경로로 사용하지 않는다.

지도 준비와 경로 표시를 바꾸는 담당자는 해당 본문과 활성화·Policy·저장 용량의 영향받는 설명을 함께 갱신한다. 작업 진행과 테스트 실행 수치는 Work에서 관리한다.
