# 설명과 근거 기준의 호환 진입

현재 공통 기준은 [스킬 shared의 설명과 근거 기준](../../../.claude/skills/shared/explanation-and-evidence-criteria.md)이 소유한다. 적용 조건·근거 범위·수명과 제거 조건은 그 본문을 읽는다. 현재 consumer는 work-discussion과 explain이며, 제품 계약·상태·수락의 Owner는 바뀌지 않는다.

이 regular-file 경로는 기존 Workspace001의 verify evidence와 과거 Decision·기록의 참조를 위해 유지한다. 현재 본문을 두 벌 관리하지 않는다. 당시 본문은 Git 이력에서 확인하며, 이 안내가 과거 판본 자체의 보존을 대신하지 않는다. 새 읽기 경로는 shared 원본을 직접 가리킨다.
