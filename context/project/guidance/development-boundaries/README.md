# 구조·UI·schema 개발 기준

이 묶음은 코드를 어느 책임에 두고, 재사용과 공유 계약의 경계를 어떻게 유지할지 설명한다. 현재 소스의 모든 배치를 모범 사례로 승인하지 않으며, 개발 기준과 확인된 예외를 구별한다. 전체 구현 위치·지원·검증 범위는 [현재 구조](../../current/architecture.md)가 맡는다.

현재 적용은 [시작 본문](INDEX.md)에서 작업에 맞는 계층·UI·schema 본문을 선택한다. [_background](_background/README.md)는 이 구분을 선택한 이유, 과거 대안과 현재 설명을 바꾼 근거를 보존한다. 형성 의도를 확인하거나 책임을 바꿀 때 읽는다.
