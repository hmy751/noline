# 여행 접근 설명의 형성 자료

[현재 본문](../INDEX.md)의 목적과 선택 이유를 복원하기 위한 자료다. 현재 적용은 본문을 따르며 과거 구현 예시를 현재 규칙으로 읽지 않는다.

- 책임 분리·조회 조합·목록·초안 보존을 왜 이렇게 구성했는지 판단할 때 [형성 맥락](context.md)을 읽는다.
- 채택·기각·보류의 당시 조건이나 사용자 발화를 확인할 때 [형성 근거](evidence.md)의 관련 절을 읽는다. 필요한 근거를 이 단위에 보존했으므로 옛 Policy·결정·아카이브를 기본 읽기 경로로 사용하지 않는다.
