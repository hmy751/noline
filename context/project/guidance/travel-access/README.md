# 여행 접근과 화면 복구

이 단위는 Policy와 Router의 책임, 계정 전체 여행 목록·선택, 네트워크 관측·조회 실행·캐시 표시·복구의 계약과 현재 연결을 관리한다. 데이터 준비·sync·cleanup 알고리즘은 해당 Owner가 유지한다.

현재 동작을 이해하거나 화면·조회·정책을 바꿀 때 [본문](INDEX.md)을 읽는다. 본문 첫 표에서 변경하려는 기능에 해당하는 절을 고른다. 각 절은 적용할 기준과 현재 구현을 함께 설명하며, 작성 계약을 충족하지 못하는 일정 수정의 차이도 구별한다.

[_background](_background/README.md)는 본문이 형성된 목적·선택 이유·보류와 근거를 보존한다. 기존 방향을 재검토하거나 본문의 의미를 바꿀 때 필요한 자료를 고른다.
