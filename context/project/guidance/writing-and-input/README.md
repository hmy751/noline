# 작성·입력의 값과 수명

이 묶음은 일정·경비 작성에서 초안·검색 후보·선택창의 임시값·저장 요청이 어떻게 이어지는지 설명한다. 여행 날짜·시각과 경비 date-only의 의미·저장 경계는 [날짜와 시각](../../common/date-and-time.md)이 소유한다.

현재 적용은 [시작 본문](INDEX.md)에서 초안·장소·picker를 선택한다. [_background](_background/README.md)는 단일 작성 수명과 Places 계약, 경비 연결·TimeField의 선택 이유와 받아들인 비용을 보존한다. 의미를 바꾸거나 과거 선택을 재검토할 때 읽는다.
