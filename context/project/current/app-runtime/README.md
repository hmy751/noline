# 앱 실행·세션·데이터 보존

앱 시작부터 인증 복원, 로컬 이용, 로그인·로그아웃까지 이어지는 현재 구조를 설명한다. 여러 모듈이 같은 여행 데이터를 다루는 조건과 종료 순서를 함께 이해하기 위한 단위다.

- 현재 동작을 이해하거나 바꿀 때는 [본문](INDEX.md)을 읽는다. 준비 완료의 의미, 인증 상태별 접근, 세션 변경과 DB·동기화의 관계를 소유한다.
- 이 구조를 선택한 이유나 과거 정책을 재검토할 때는 [형성 자료](_background/README.md)를 읽는다. 당시 대안·정정과 최소 근거를 보존하며 현재 적용할 답은 본문에서 찾는다.

기존 Activation Router·Policy·transaction·cleanup 정책의 상세 Owner는 유지한다. 본문은 그 정책이 앱과 세션 수명에 어떻게 연결되는지 설명하며, 서버 인증 설계·네트워크 관측 전체·DB migration·지도 정리 전체를 소유하지 않는다.

관련 제품 의미의 결정 책임과 갱신 권한은 [Project 관리 계약](../../MAINTENANCE.md)을 따른다. 앱 준비·인증·DB·sync 구현을 변경하는 주체가 본문과 실제 진입 경로를 함께 맞춘다. 상위 구성은 [현재 구현 맥락](../README.md)에서 찾는다.
