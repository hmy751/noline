# 공통 맥락 사용 방법의 형성 자료

이 층은 [USAGE](../../USAGE.md)의 목적과 선택 이유, 원문 직접 읽기·Work current·지속 본문 반영의 관계를 보존한다. 현재 요청에 적용할 방법은 USAGE에 있고, 이 자료는 그 뜻을 더 정확히 이해하거나 배치·책임을 바꿀 때 선택한다.

- 일반 읽기를 별도 스킬 호출보다 공통 참조로 둔 이유와 남은 사용감: [형성 맥락](context.md).
- 기존 read 기능을 공통화하고 영역별 내용 책임을 유지한 범위: [적용 기록](records/2026-10-26-common-usage.md).
- 개발 중 자연스러운 사용·직접 요청, 형태에 대한 유보와 외부 고정판 근거: [발췌와 출처](evidence.md).

과거 대안·잠정 선택과 실제 적용 결과를 구별한다. 이 문서의 존재는 모든 담당자의 올바른 읽기나 운영 환경의 자동 발견을 증명하지 않는다.
