# 2026-10-26 — 공통 읽기 방법을 prototype에 적용

대상 본문은 [USAGE](../../../USAGE.md)다. 개발 중 담당자 직접 읽기와 별도 요청을 같은 방법으로 연결하되, 읽기와 지속 본문 반영의 권한·결과를 구별하기 위해 공통 읽기 참조와 context-update를 적용했다.

기존 read의 일반 방법을 USAGE에 모으고 Project reading에는 제품별 질문·계약/지원 대조를 남겼다. Personal 입구도 같은 공통 방법으로 연결하면서 기준·사례·선택 권한을 유지했다. development의 적용 시점·반환·전체 판단과 Work 재개 순서는 각 기존 책임에서 연결한다.

하나의 context 스킬에 읽기·반영을 묶는 안도 비교했지만 현재는 잠정 합의의 참조+한정 반영 과업으로 펼쳤다. 이 선택에 실제 우월성이 입증된 것은 아니며, 사용자가 지적한 분리 형태의 사용감은 계속 확인할 대상이다. [형성 맥락](../context.md)과 [직접 발화·외부 근거](../evidence.md)를 함께 읽는다.

이 기록은 본문 구성·연결의 변경 이유다. 실제 운영 스킬 설치·자동 발견·여러 역할의 전체 수행 효과를 확인한 기록으로 사용하지 않는다.
