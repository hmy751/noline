# 경험 체계와 실행 수단의 관리 책임을 정리한 기록

2026-10-29. [Personal 형성 맥락](../context.md)과 [근거](../evidence.md)를 구별하고, [경험 관리](../../../experience/MAINTENANCE.md)에는 경험의 보존·조회·갱신을 남겼다.

처음에는 Personal의 직접 근거를 루프 스킬에 두었다가, 스킬을 교체해도 근거를 보존하려고 Personal의 context에 옮겼다. 이때 ‘발췌가 짧다’는 이유로 설명과 근거를 한 파일에 둔 Main의 절충은 CONTENT-POLICY의 책임 구분과 맞지 않았다. 사용자가 구조 일관성을 다시 지적했고, 근거를 같은 폴더의 evidence로 분리하는 안을 선택했다. 발췌 두 개가 실제 존재하므로 빈 형식을 만드는 변경이 아니다.

경험 관리 본문에도 대화를 먼저 훑으라는 전체 루프 순서가 들어 있었다. 현재 모음은 경험의 조회·근거 대조·갱신을 소유하고 전체 수행 순서는 실행 수단이 소유하도록 정리했다. 일반 작업의 채택 기준과 아직 채택하지 않은 경험·후보를 구별하는 계약은 유지한다. 실제 실행 수단을 제거하는 시험이나 사용 효과 확인은 아니다.
