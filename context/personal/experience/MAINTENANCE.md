# 경험·해석·후보를 보존하고 다시 찾는다

[경험 모음](README.md)의 내용·관리 계약이다. Personal의 선택 권한은 사용자에게 있고 허용된 편집은 현재 Main 또는 지정 담당자가 수행한다. 루프 스킬은 이 계약을 사용하는 실행 수단이며 저장소의 소유자가 아니다. 해당 스킬이 없어져도 이 모음과 읽기·갱신 관계는 유지한다.

## 필요한 내용을 기존 주제에 잇는다

협업 경험·판단 자료와 아직 반영하지 않은 관련 후보를 여기 남긴다. 기존 주제·아직 묶지 않은 기록을 먼저 대조해 같은 발견을 중복 생성하지 않는다. 후보 없이 좋은 경험이나 열린 의문만 남길 수 있다. 모든 제품 버그·실행 과제를 여기 복사하지 않으며 실제 작업이 소유하는 내용은 그 대상과 연결한다. Work의 범위를 새로 제한하지 않는다.

주제별 상세는 현재 이해, 이를 지지하거나 제한하는 실제 경험, 열린 후보가 있다면 그 내용·미결 이유·다시 볼 조건, 이후 선택과 실제 대상의 관계를 설명한다. 관찰과 해석, 채택과 실제 반영·확인을 구별한다. 모든 항목을 채우는 고정 양식·점수·기한·반복 수를 요구하지 않는다. 재검토 조건 자체가 아직 불명확하면 그대로 밝힌다.

정확한 문구·순서가 근거이면 최소 발췌와 출처·당시 조건을 함께 남긴다. 긴 원문은 기존 보존 위치로 연결하고 새 보존이 필요하면 주제 가까이에 필요한 범위만 둔다. 현재 해석은 고칠 수 있지만 과거 사실과 당시 이유를 새 결론에 맞춰 덮지 않는다. 반대 경험도 남긴다.

주제를 아직 정하기 어렵다면 길잡이의 ‘아직 묶지 않은 기록’에 장면과 의문을 남긴다. 길어지면 의미 있는 이름의 별도 기록을 연결한다. 미리 빈 주제·폴더·파일 세트를 만들지 않는다. 합치거나 나눌 때 근거와 이전 판단을 이어주고 기존 진입을 갱신한다.

## 관련 경험을 다시 찾아 갱신한다

관련 경험을 조회할 때는 길잡이의 주제 요약과 아직 묶지 않은 기록을 확인한다. 의미·사용 조건이 이어지는 주제의 경험·반례·이전 선택을 읽고 새 경험을 대조한다. 새 근거·상황·우선순위 없이 같은 보류안을 매번 다시 권하지 않는다. 낡은 해석이나 중복 후보가 보이면 새 경험과 함께 조정한다.

선택이 바뀌면 무엇을 왜 채택·보류·접었는지와 실제 반영·남은 일을 주제에서 구별한다. 반영된 후보는 열린 후보에서 빼고 실제 대상과 확인 결과로 연결한다. 한정 시도는 적용 상황과 이후 판단에 필요한 관찰을 밝혀 일반 채택과 구별한다. 실제 수행할 작업과 읽을 위치가 정해졌다면 그 연결을 남기고, 미정이면 실행 연결이 남았음을 밝힌다. 시도가 끝나면 같은 주제에서 실제 사용·미사용, 도움·부담·미확인과 선택 이유를 갱신하고 필요한 작업 결과를 연결한다. 실행 지침 전문은 복제하지 않으며 실행이 남아 있으면 완료로 표시하지 않는다.

채택 기준·스킬의 현재 내용은 실제 반영 대상이 소유한다. 주제에서는 경험과 선택 이유·연결을 남기며 전문을 복제하지 않는다. 반영되지 않은 후보·해석이 평소 실행 지침에 섞이지 않게 한다. 현재 적용할 기준을 관련 Personal 입구나 기존 스킬에서 찾을 수 있어야 한다. 해당 본문의 형성 자료가 이 경험을 참고할 수 있지만 `_background`를 모든 후보의 공통 수집함으로 만들지 않는다.

효과는 실제 사용·도움·부담을 구별해 기록한다. 원문 접근이 없는 구간은 모르는 것으로 남기며 다음 루프에서 필요한 경우 회수한다. 후보가 접혀도 유효한 경험은 보존할 수 있다. 일반 작업마다 이 모음 전체를 읽거나 매 대화 평가를 요구하지 않는다.

## 반영 후 확인한다

[Personal 입구](../README.md)에서 관련 주제·열린 후보·아직 묶지 않은 기록을 찾아 근거와 미결 이유를 복원한다. 기존 주제와 중복되거나 사실·후보·채택이 혼동되지 않는지, 반영된 대상과 안내가 맞는지 확인한다. 길잡이는 짧은 요약·진입만 유지하고 상세의 별도 정본으로 만들지 않는다.

Noline의 모음은 로컬 Personal에 있다. 여러 저장소의 동기화·자동 회수는 구현하지 않았다. 다른 Project에 이식할 때는 대상의 Personal 위치를 먼저 확인하고 일반 진입에서 같은 자료를 다시 찾을 수 있게 연결한다. 보존 기록을 새로 만들었다는 사실은 방법의 효과를 입증하지 않는다.
