# 코드 표현과 진단

코드를 읽는 흐름, 주석이 보완할 내용, 실패 처리 뒤 필요한 진단 정보를 판단하는 개인 기준이다. 이름·완료의 의미와 오류·수명 계약은 각각의 기존 주제가 맡는다. 이 주제는 그 의미를 읽고 조사할 때 필요한 표현을 다룬다.

[현재 본문](INDEX.md)은 처리 목적별 묶음·배치·주석·진단의 판단과 적용 조건을 소유한다. 코드를 쓰거나 고칠 때 해당 부분을 읽는다. 이름·상수의 의미·완료 범위는 [이름과 완료](../naming-and-completion/INDEX.md), 실패 분류·비대기 작업의 책임은 [계약과 수명](../contracts-and-lifetime/INDEX.md)에서 함께 판단한다.

[형성 자료](_background/README.md)는 이 기준을 만든 의도·배경·선택과 근거를 보존한다. 왜 개인 기준으로 나눴는지 이해하거나 의미·적용 범위를 바꿀 때 필요한 자료를 고른다. 현재 기준의 추가 의무 목록으로 읽지 않는다.

Project가 실제 formatter·logger·수집 필드·민감 정보·제품 계약을 구체화하고, 개발 흐름이 변경 수행과 동작 확인을 맡는다. 이 주제의 구성·보존·갱신은 [공통 관리 원칙](../../../CONTENT-POLICY.md)을 따른다.
