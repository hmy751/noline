# 코드 표현 기준의 형성 자료

[현재 본문](../INDEX.md)을 만든 목적·배경·선택과 필요한 원문을 보존한다. 현재 내용이 왜 이 구성으로 남았는지 이해하고, 의미를 바꾸거나 다시 검토할 때 사용한다. 현재 적용할 기준은 본문이 소유하며 과거 자료에는 아직 확인하지 않은 해석·대안도 있다.

- 기존 제품 가이드에서 무엇을 이어받고 왜 별도 주제로 나눴는지는 [형성 맥락](context.md)을 읽는다.
- 개인 기준과 제품 계약을 구별한 사용자 발화, 보존 가이드의 실제 문구와 확인 범위는 [근거](evidence.md)를 읽는다.
- 이번 prototype 반영의 권한과 효과 확인 한계는 [적용 요청](evidence.md#프로토타입-적용-요청)을 확인한다.

전체 주제의 구성과 연결 본문은 [주제 안내](../README.md)에서 찾는다.
