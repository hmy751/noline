# UI 판단은 실제 화면과 그 결정이 영향을 주는 조건으로 확인한다

**언제 쓰나:** UI 변경의 결과를 확인할 때, Storybook이나 테스트의 범위를 정할 때, 시안과 앱을 연결할 때.

**핵심 규칙:** 코드만 읽고 보인다고 말하지 않는다. 실제 진입점에서 화면을 띄워, 그 결정에 영향을 주는 조건으로 확인하고, 보지 못한 조건은 결과에 적는다.

시작 본문은 [UI 결정을 맡을 책임에 두고 쌓는다](INDEX.md)다. 실행 방법과 도구는 Project가 소유한다.

## 화면과 기기의 관찰을 코드 추측보다 앞세운다

- **관찰로 판단한다:** 코드만 보고 흐린 버튼을 비활성이라고 설명했는데 실제 기기에서는 눌린 일이 있었다. 동작을 단정하기 전에 화면에서 본다.
- **비교 대상을 쓴다:** 시간 선택 휠은 다른 앱의 스크린샷과 나란히 놓고 "따라가기 어렵다"는 관찰에서 바뀌었다. 전후 캡처나 참고 화면과 비교한다.
- **완료 조건:** 사용자가 실제 기기에서 확인해야 끝나는 변경은 그 조건을 숨기지 않는다. 대신 확인했다고 말하지 않는다.
- **캡처 보존 위치:** Project의 규칙을 따른다.

## 결정에 영향을 주는 조건을 고른다

| 조건 | 이런 변경에서 본다 |
| --- | --- |
| 긴 글자, 두 줄 제목 | 제목과 액션, 버튼, 탭 |
| 큰 글꼴 | 고정 높이, 측정 위치, 버튼 글자 |
| 작은 화면, 회전 | 시트 내용, 하단 액션, 측정 위치 |
| 키보드 | 폼의 마지막 필드와 저장 버튼 |
| 목록의 첫·끝 항목, 스크롤 후 | 떠 있는 메뉴 |
| 안내가 추가된 상태 | 헤더, 안전 영역, 배너 |
| 로딩·오류·빈 상태 | 상태 전환, 자리 유지 |
| 여러 언어 | 글자 길이가 달라지는 앱 |
| 화면 폭 전환 | 웹의 breakpoint 주변 |

모든 조건을 매번 보지 않는다. 바꾼 결정과 관련된 것을 고르고, 나머지는 보지 않았다고 말한다.

## Storybook은 경험을 표시하고 역할은 정하지 않는다

**미정:** Storybook을 쓸지, 무엇을 맡길지. 쓰게 되면 아래 경험을 참고한다.

- **보이는 것:** 개별 부품이 어떻게 생겼는지 보기에 좋다. 어떻게 조합하는지와 언제 쓰는지는 별도로 필요하다고 판단한 적이 있다.
- **조합 스토리:** Form·Card·Grid 조합은 스토리로도 보여 줄 수 있었지만, 상황에서 찾아 실제 코드로 옮기는 경로가 약했다.
- **상태 스토리:** 대부분 기본 상태만 있었다. 오류와 로딩을 재현하는 스토리를 쓰면 쉽게 보기 어려운 상태를 확인할 수 있다.
- **환경 비용:** 테마, 번역, 전역 스타일, 프레임워크, store를 앱과 맞추는 데 많은 수정이 들었다. 앱 의존 스토리는 공통 부품 스토리와 분리한 적이 있다.
- **쓰지 않은 것:** play 테스트, 시각 회귀. 설치만 된 addon은 쓴 것으로 세지 않는다.
- **React Native:** 앱에서 사용을 확인하지 못했다.
- **재구현 위험:** 시안 뷰어에 실제 컴포넌트를 다시 구현해 두면 실제와 달라진다. 보여 주는 것이 실제 부품인지 확인한다.

## 컴포넌트 테스트는 동작을 잠그고 모양은 화면으로 본다

여러 프로젝트에서 테스트는 렌더링, 터치 분기, 메뉴 위치, 복구 흐름, 접근 가능한 이름 같은 동작을 향했고 스타일과 variant 조합은 거의 다루지 않았다.

- **먼저 고정할 것:** 위험한 로직과 고치며 드러난 동작.
- **조회 방식:** 사용자가 보는 역할과 이름으로 찾는다.
- **스타일:** 최소로 두고 화면으로 확인한다.
- **미정:** 스냅샷과 시각 회귀, 공통 부품의 테스트 범위.

## 시안과 앱의 연결은 Project가 정하고 경로를 확인한다

시안을 앱과 별도로 만들면 적용 경로가 없을 때 어휘와 값이 갈라진다. 시안 저장소의 규칙과 앱 코드가 끊겨 있던 경험이 있다. 시안에서 작업할 때는 어떻게 앱에 들어갈지 묻는다. 시안의 값과 어휘를 앱 기준처럼 쓰지 않는다. 시안 적용 여부는 제품 결정이므로 코드가 다르다고 곧바로 고치지 않는다.

디자인 도구와 코드 연결은 **미정**이다.
