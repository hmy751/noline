## README 판본

커밋된 판본은 git에서 꺼내 읽는다. 과거 판본을 여기 복제하지 않는다.

| 판본 | 접근 | 읽을 이유 |
| --- | --- | --- |
| 2026-03 판 | `git show a43757e3:README.md` | 고민 → 대안 → 해결 형식의 원형. 지금 근거를 확인할 수 없는 수치가 섞여 있어 그대로 되살리지 않았다. |
| 2026-10-31 판 | `git show bebf1232:README.md` | 이번 작업의 출발점. 사용자가 갈아엎고 싶던 것은 아니라고 한 판이다. |
