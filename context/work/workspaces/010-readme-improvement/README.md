# 010 — 루트 README를 Project context와 코드에 맞춰 다시 쓰기

저장소 루트의 [README](../../../../README.md)를 처음 보는 개발자가 끝까지 읽고, 무엇을 만들었고 어떤 고민을 했는지 알 수 있게 다시 쓴 독립 Work다. 문장의 근거는 Project context와 실제 코드에 두고, 저장소 주인이 프론트엔드 엔지니어라는 점이 드러나게 했다.

**2026-11-15 현재 README 재구성·코드 대조·UI State 절 추가까지 반영해 main에 push했다.** GitHub에서의 렌더링 확인과 몇 가지 보강 제안은 남아 있다.

[재개 안내](recover.md)에서 시작한다. current는 이 README가 지켜야 할 기준과 현재 상태, source는 대화 원문과 판본 접근점, output은 실제 결과 위치, records는 구성·문안을 고른 과정과 버린 안을 맡는다. 제품 의미의 정본은 Project에 남으며 이 Work는 README가 그것을 어떻게 요약할지만 다룬다.

이 Work 생성으로 기본 Workspace나 실제 채팅 연결은 바꾸지 않았다.
