# 완료를 판단할 근거

README 변경을 마쳤다고 판단하려면 다음을 실제로 확인한다.

- **사실:** 고친 문장이 가리키는 코드를 읽어 동작이 일치한다. 인용 블록이 소스와 같다. 링크한 파일과 문서 앵커가 있다.
- **읽기:** 처음 보는 개발자가 앞에서부터 읽어 막히지 않는다. 용어가 설명보다 먼저 나오지 않고, 한 문단이 여러 결론을 압축하지 않는다.
- **분량:** 더한 만큼의 이유가 있다. 같은 내용을 다른 절이 이미 말하고 있으면 한쪽으로 모은다.
- **사용자 수락:** 구성·제목·문안의 방향은 사용자가 본 초안을 기준으로 한다. 사용자가 보지 않은 구성 변경을 완료로 보고하지 않는다.
- **게시 결과:** GitHub에서 목차 링크, 표, mermaid 다이어그램, 이미지 그리드가 의도대로 보인다.

다음은 완료 근거가 아니다. `pnpm harness:check`에서 README 관련 항목이 없다는 것은 링크 형식의 확인일 뿐이다(이 검사는 과거 Workspace의 끊긴 링크 64건 때문에 전체로는 실패하며, 이번 작업과 무관하다). 독립 리뷰어의 추천도 판단 재료이지 수락이 아니다.

확인하지 않은 범위는 그대로 남긴다. 이번 작업에서 README가 링크한 테스트는 실행하지 않았고, 실제 앱 화면도 보지 않았다. 문구와 분기는 소스 기준이다.
