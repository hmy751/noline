# 008 — 앱의 예외 안내를 상황별 규칙으로 정리하기 재개

예외 안내의 규칙을 정하는 작업이다. 현재 조사·결정 단계와 열린 선택을 state와 해당 Ticket에서 읽고 구현 여부를 구별한다.

일반 재개는 [목표와 범위](current/memory/spec/01-problem-goal-scope.md), [현재 상태와 다음 행동](current/state/index.md), [산출물 위치](output/index.md)를 읽는다. 한정 요청은 해당 자료부터 본다.

특정 실행의 합의는 [Ticket 색인](current/memory/tickets/index.md), 과거 선택·검사 근거는 [기록 색인](records/README.md)에서 해당 항목만 선택한다. 제품·개발 기준은 [이 작업의 Project 선택](current/memory/project-context.md)에서 해당 주제와 이유를 찾아 읽는다.

검증 요청은 [품질·완료 기준](current/memory/spec/04-quality-and-completion.md)에서 주장과 범위를 확인한다. 이전 Verify는 재개 설정의 JSON 구문만 확인했다. 현재 요청에 해당하는 문서·제품 검사를 직접 선택한다.

사용자 발화 원문은 [source](source/index.md), 생성 때의 판단은 [생성 기록](records/2026-11-04-01-workspace-creation.md)에 있다.
