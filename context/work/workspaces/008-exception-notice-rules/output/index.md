# 산출물과 읽을 이유

저장소에서 32개 상황별 관찰·변경 제안·문구·행동 뒤의 결과·확인 조건을 읽을 수 있다. 다른 체크아웃에서도 이 문서로 논의를 이어간다. [화면별 논의 초안](screen-proposals.md) · [전체 화면·정책을 대조한 경위](../records/2026-11-15-01-discussion-scope-and-proposals.md)

[촬영 화면과 제안 예시로 보는 처리안](../../../../../artifacts/2026-11-10-008-notices/review.html)에서 Ticket 02의 논의를 시작한다. 32개 상황마다 촬영 화면과 생성 예시를 나란히 비교하고, 아래에서 현재 관찰, 변경 제안, 문구, 행동 뒤의 결과와 확인 조건을 읽는다. 원본 40장을 촬영 시점과 함께 연결했고 생성 예시 32장에는 가정과 조건을 표시했다. 사진 전환과 확대도 가능하다. 제안은 사용자와 논의할 초안이다. [생성 예시 추가와 확인 범위](../records/2026-11-13-02-proposal-examples.md)에서 이번 보완을, [최초 정리본 기록](../records/2026-11-13-01-screen-review-page.md)에서 앞선 요청을 찾는다.

[전체 화면 갤러리](../../../../../artifacts/2026-11-10-008-notices/index.html)는 Ticket 01이 모은 40장 전체를 훑어볼 때 사용한다. 이미지와 두 페이지는 이 체크아웃에만 있다. [촬영 기록](../records/2026-11-10-01-notice-screens.md)에서 재현 조건과 확인 범위를 찾는다.

안내 규칙은 Ticket 02에서 사용자와 정하고, 이에 따른 화면 변경은 Ticket 03~06에서 다룬다. 현재 단계는 [state](../current/state/index.md)에서 확인한다.
