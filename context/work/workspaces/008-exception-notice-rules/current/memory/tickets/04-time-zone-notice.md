# 04. 시간대 안내와 확인 흐름

## 맡은 결과와 범위

시간대 없는 여행의 안내가 맥락에 맞게 나오고, 확인 흐름을 끝까지 쓸 수 있게 한다.

## 실행 맥락과 접근

**지킬 의미:** [날짜와 시각](../../../../../../project/common/date-and-time.md)은 시간대 도입 전 여행의 UTC 호환 표시를 확인 필요 안내와 함께 쓴다고 정한다. 사용자에게 뜬금없다고 해서 그냥 지우면 시각이 왜 UTC인지 알 길이 없어진다. 안내를 줄이거나 옮기려면 이 의미를 어떻게 지킬지 함께 정한다.

**확인한 사실** ([안내 현황 기록](../../../../007-sync-failure-recovery/records/2026-11-04-01-notice-inventory.md#시간대-확인))
- "시간대 확인 필요 · UTC 기준"이 홈 카드, 일정·경비 화면, 시트에 반복된다.
- "여행 시간대 확인"은 시간대 창이 아니라 "여행 편집" 시트 전체를 연다. 시트 안 버튼 이름은 "도시 시간대 확인"이다.
- 오프라인에서는 같은 제약을 세 번 말한다.

**모르는 것:** 실제 온라인 동작은 Ticket 01에서 확인한다. 사용자가 말한 "잘 안 된다"가 무엇인지에 따라 이 Ticket의 범위가 달라진다.

경비 화면에서 안내가 헤더 위로 올라가는 겹침과 시트 닫기·잘림은 개별 수정 후보다.

## 완료 조건과 확인 방법

- 시간대 없는 여행에서 안내가 정한 곳에만 나오고, UTC 표시의 이유를 알 수 있다.
- 온라인에서 확인을 끝까지 마칠 수 있고, 저장된 시각이 옮겨지지 않는다.
- 오프라인에서 왜 지금 못 하는지 한 번만 말한다.

## 현재 상태와 실제 결과

실행 전. Ticket 01·02를 기다린다.
