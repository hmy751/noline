# 변경 제안을 보여주는 예시 이미지 추가

사용자는 “좋아 근데 하나 더 보완하고 싶은게 니가 제안하는 변경 말과 더불어서 니가 생각하는 예시로 이미지 만들어서 이미지도 추가해놔주면 좋겠어”라고 요청했다. 원문은 Codex 대화 `01a1c4af-93cd-7ba0-8036-5e1e2d37ea53`의 737행에 있다.

[검토 페이지](../../../../../artifacts/2026-11-10-008-notices/review.html)를 보완해 32개 상황에 서로 다른 생성 예시 32장을 붙였다. 촬영 원본 40장을 모두 연결하고, 항목마다 촬영 화면과 제안 예시를 나란히 배치했다. 그 아래에서 문구·행동·확인 조건을 읽고 각 이미지를 확대할 수 있다. 예시의 캡션에는 기기에 준비된 여행의 존재처럼 해당 화면이 가정한 조건과 논의용 시안임을 표시했다.

Main은 내장 이미지 생성 도구로 모든 예시를 만들고 직접 보면서 확인했다. 설명과 맞지 않게 추가된 슬로건, 로그인 화면의 하단 탭, 이메일 로그인 배경 등이 있는 6개 이미지를 보정했다. [생성 요청 기록](../../../../../artifacts/2026-11-10-008-notices/proposals/prompts.json)에 항목 제목, 파일, 실제 생성·보정 요청문과 생성 원본 경로를 남겼다.

Main은 원본 40개와 생성 예시 32개의 파일 존재·이미지 무결성, 예시 32개와 생성 요청 32개의 항목 연결을 검사했다. DOM 대체 환경에서 32개 항목 이동, 촬영 사진·확대 전환 42회, 생성 예시 확대 32회를 확인했다. 실제 브라우저 배치는 로컬 파일 접근에 대한 도구 제한으로 확인하지 못했다.

이번 결과는 제안 모습을 비교하며 논의할 자료를 보완한 것이다. 사용자와 안내 규칙을 정하는 Ticket 02는 계속 열려 있다.
