# 작업의 판단과 기록

현재 실행 상태는 [state](../current/state/index.md), 실행 정의는 [Ticket](../current/memory/tickets/index.md), 주제별 실제 결과·검증은 [output](../output/index.md)이 소유한다. 이 색인은 왜 범위와 판단이 바뀌었는지 다시 확인할 기록을 묶는다. 당시 원문과 판단은 그대로 보존하며 오래된 권고를 현재 기준으로 읽지 않는다.

새 세션이 작업 흐름을 복원하려면 **아카이빙 의도 교정 → 내용·형식 판단 → 현 위치 유지 전제 교정과09–13 구성**의 기록을 우선 고른다. 나머지는 해당 근거가 필요할 때 내려간다.
