# Ticket 02 — 제품·활성화·네트워크 접근 재구성

상태: 완료. 2026-10-31, 제품·여행 접근·Router/목록·화면 복구의 설명과 읽기 경로에 더해, 재개했던 변경 문서 전체의 역할·구성 교정과 독립 재확인을 마쳤다. 이 완료는 문서 이관 범위이며 제품 구현 차이나 006 전체 이관의 해소를 뜻하지 않는다.

## 맡은 결과와 범위

제품 기준에서 활성화·연결 상태에 따른 사용자 동작과 데이터 보존 이유를 이해할 수 있게 하고, 네트워크 관측·여행 조회·화면 복구의 현재 계약을 코드와 대조해 Project의 명확한 Owner로 옮긴다.

완료 상태에서는 현재 가이드와 Project 본문만으로 현재 의미와 필요한 선택 이유를 이해할 수 있어야 한다. `.claude/context`와 관련 옛 Policy·decision 문서나 그 아카이브로 읽기를 안내하지 않는다. 옛 자료는 일반 읽기에서 제외되는 아카이브로 격리하거나 제거할 수 있으며, 보존 위치나 물리적 삭제는 이 Ticket의 목적이 아니다. 활성화·sync·폼 상세처럼 다른 Ticket이 맡는 의존은 담당과 해소 시점을 명시한다. 이관 전 임시 상태를 최종 Owner 구성으로 승인하지 않는다.

## 실행 맥락과 접근

첫 조사의 제품·활성화·네트워크 후보에서 시작해 원문·후속 결정·현재 코드와 실제 소비자를 대조했다. 처음에는 낡은 타입 지시, 약해진 기록 우선의 이유, 기준과 일정 수정 구현의 혼동을 놓쳤다. 후속 검토에서 정정했으며, 그 수정의 확인을 문서 전체의 정확성 보장으로 확대하지 않는다.

사용자가 체크리스트의 구성 판단을 물은 뒤에는 내용 대조와 형식·역할 판단을 구별해 변경 문서 전체를 다시 살폈다. 기존 형식이 유용하면 유지하고, 적용 조건·행동·설명 책임이 흐려지거나 중복되면 재구성했다. 공통 적용 기준은 [Spec 04](../spec/04-quality-and-completion.md#후속-ticket의-내용-판단과-리뷰)가 소유한다.

## 실제 결과와 확인

제품 기준은 활성화·연결 상태별 데이터 관계와 목록·읽기 내용·초안의 서로 다른 보존 이유를 설명한다. 여행 접근은 Policy·Router·목록·조회·화면 복구를 함께 소유하며, 사용 조건과 핵심 규칙에서 필요한 상세로 이어진다. 필요한 선택 이유·기각 대안·사용자 발췌는 Project 형성 자료에 보존했다.

현재 본문·형성 자료에서 옛 제품 문서·결정·아카이브로 돌아가는 읽기 연결을 없앴다. 옛 Policy 호환 파일은 제거했고 관련 rule·guard·가이드·command reference는 새 Owner에 연결했다. 잘못된 중간 이관안은 역사 archive로 구분했다. 원본 대응과 남은 미이관 범위는 [이관 결과](../../../output/ticket-02-result.md)에 있다.

별도 체크리스트는 각 적용 조건에 통합했지만, 상태 비교표·제품 장면·결정 이유·compact rule처럼 역할에 맞는 구성은 유지했다. 주변 입력 가이드의 구현 일반화와 오류 코드 예시의 범위 누락도 보완했다. 독립 리뷰에서 재배치 중 빠진 사용자 안내 기준과 앵커 문제를 찾아 수정한 뒤 좁게 재확인했다. 상세 유지·변경 판단과 대표 읽기 결과는 [내용·구성 재리뷰](../../../output/ticket-02-content-review.md)가 맡는다.

제품 코드가 아닌 문서 변경은 실제 Project 이관·구성 정비·참조 전환 커밋 `fe18d51`과 006 조사·검토 결과·후속 판단 기준 커밋 `725e6d5`로 분리했다. 기존 Personal 변경 2개와 `.pnpm-store/`는 두 커밋에서 제외했으며, Main은 push하지 않았다고 보고했다.

제품 코드는 변경하지 않았다. 앞선 7 suites·146 tests 통과는 Router·목록·Policy·관측·Query·화면 연결의 제한된 근거이며, 일정 수정 화면의 연결 전환 중 입력 표시·내부 값 보존을 입증하지 않는다. 이번 구성 교정은 문서·원문·직전 판본의 정적 대조이며 제품 검사를 새로 실행하지 않았다. 앞선 문서·Recover 확인과 역사 링크 영향은 [확인 기록](../../../records/2026-10-31-02-ticket-02-migration-result.md), 이번 구성 판단과 사용자 원문은 [후속 기록](../../../records/2026-10-31-04-document-role-and-format-review.md)에 남긴다.
