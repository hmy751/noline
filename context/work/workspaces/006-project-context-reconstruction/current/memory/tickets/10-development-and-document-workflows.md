# Ticket 10 — 반복 개발·문서 관리 절차 통합

## 맡은 결과와 범위

같은 개발·문서 작업에 여러 절차, 기록 위치와 정책 원천을 제시하는 상황을 없앤다. runbooks·workflows·옛 commands·deprecated noline-work에 남은 유효한 수행 방법은 현재 실행·관리 체계에 받아들이고, 낡은 지시·중복 절차와 옛 호출 경로를 정리한다.

대상에는 반복 개발 runbook과 workflow, `check-docs`·`doc-save`·`doc-discuss`·`doc-refactor`·`generate-pr`, noline-work의 원본·bridge·발견 설정이 포함된다. 개발·context 갱신·설명·작업 논의·앱 실행에 관여하는 관련 skill의 워크플로와 그 skill이 선택하는 지침·관리 계약도 함께 대조한다. 스킬을 단순 분배기로 가정하거나 관련 지침과 떼어 평가하지 않는다.

제품 기준 자체는 Ticket 09가 정한 Owner를 사용한다. 남은 공통 실행 기준·agent·host 연결의 전반적인 재배치는 Ticket 11이 맡지만, 이 Ticket에서 바꾸는 호출·발견 연결을 깨진 상태로 11에 미루지는 않는다.

## 실행 맥락과 접근

[09–13 구성](../../../output/ticket-recomposition-09-13.md), [추가 정리 후보](../../../output/claude-cleanup-candidates.md)와 [Spec의 내용 판단 기준](../spec/04-quality-and-completion.md#후속-ticket의-내용-판단과-리뷰)을 적용한다. runbooks·workflows·commands와 noline-work를 현재 개발·context 갱신·설명·작업 논의·앱 실행 책임 및 Project·Work 관리 계약에 대조한다.

각 skill은 호출 조건만 보지 않고 실제 판단·수행 순서, 필수 입력, 연결된 지침, 결과와 책임 경계를 함께 확인한다. 여러 skill과 지침이 같은 개발 흐름에 관여하면 각각의 역할과 적용 순서를 대조해 중복·공백·충돌을 판단한다. 제품 기준을 읽는 입력 경로와 개발 수행 워크플로를 구별하되 실제 실행에서 함께 필요한 연결은 유지한다.

각 문서 안에서도 실제 도구 실행 방법, 제품 규칙, 기록 책임과 역사 예시를 구별한다. 모든 정책 문서의 선행 읽기, commit 선행 강제, command 내부의 중복 정책 사전과 옛 저장 경로를 현재 필요에 맞춰 재판단한다. 필요한 변경 영향 확인·원문 보존·작업 순서가 현재 체계에 빠졌다면 근거와 함께 보완한다.

`generate-pr`은 기능 가치와 현재 작성 기준을 별도로 비교하며 다른 옛 문서 command와 자동으로 함께 폐기하지 않는다. noline-work의 원본·symlink·발견 설정과 workflows의 역방향 안내처럼 정리에 직접 필요한 연결은 이 Ticket에서 함께 맞춘다.

## 완료 조건과 확인 방법

- 새 Entity·API·Form 작업, 문서 갱신·논의와 PR 작성의 대표 요청에서 필요한 수행 내용과 실제 담당 경로를 찾을 수 있다.
- 관련 skill의 호출 조건뿐 아니라 워크플로·선택 지침·관리 계약을 함께 대조하고, 제품 기준 입력과 개발 수행 책임의 관계를 설명할 수 있다.
- 유효한 절차의 조건·권한·이유가 현재 Owner에 통합되고, 같은 작업을 다른 저장 위치나 정책으로 보내는 옛 지시가 현재 호출 경로에 남지 않는다.
- 제거한 기능이 여전히 필요하면 대체 경로의 실제 발견과 호출을 확인한다.
- 원본·bridge·발견 설정과 영향을 받는 guide를 함께 맞추며, 정적 링크 통과와 실제 수행 경로 확인을 구별한다.
- 각 결과에서 무엇을 통합·보강·제외·유지했는지와 그 이유를 설명한다.

## 현재 상태와 실제 결과

Ticket 09의 제품 기준 Owner 통합이 끝났으며 다음 실행은 이 Ticket이다. Ticket 09에서 구별한 Activation Router의 제품 책임과 개발 수행 흐름을 전제로, 현재 스킬의 워크플로와 관련 지침·관리 계약을 함께 대조한다.

실제 절차 통합·삭제·호출 경로 전환은 아직 시작하지 않았다. 이 Ticket에서 필요한 연결 수정을 11로 넘긴 상태로 완료하지 않는다.
