# 입력·출력과 책임

입력은 사용자–Main 원문, 당시 코드와 검증 결과, 실제 사용한 기준·스킬과 그 현재판이다. 기록은 상세 원자료로 내려가는 근거이며 사실·당시 판단·현재 해석·미채택 후보를 구별한다. 사용자 예시는 분석 방향의 단서이지 모두 독립 규칙으로 승격할 항목이 아니다.

출력은 관찰과 반대 조건을 설명할 수 있는 개선 선택, 사용자가 선택한 범위의 실제 반영과 직접 확인, 유지·미채택·미확인 범위다. 문서 작성과 이후 실사용 효과는 다르다. 사례별 판단을 연결하는 표현을 모든 업무의 의무 서식으로 만들지 않는다.

007 Ticket 09는 현재 제품의 단계별 코드 책임을, 이 Work는 검토·판단 체계의 개선을 맡는다. 서로의 파일을 자동 수정하지 않고 새 근거가 실제로 영향을 주는 부분만 연결한다. 제품의 FIFO·항목 표식·미전송 보호·삭제 소유권 정책은 이 작업으로 바꾸지 않는다.
