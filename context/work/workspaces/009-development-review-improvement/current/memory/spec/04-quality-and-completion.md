# 완료를 판단할 근거

이번 루프를 완료하려면 다음 관계가 실제 자료에서 확인돼야 한다.

- 원문의 중요한 정정과 실제 구현 선택을 복원하고, 유용했던 방식과 사용자 재지시가 필요했던 누락을 근거로 구별한다. 마지막 요약을 최종 합의처럼 인용하지 않는다.
- 개선할 내용·수행·도구를 현행과 비교하고, 어떤 실제 선택이 달라지는지와 이득·부담·반대 조건을 설명한다. 기술스택을 별도 체크 항목으로 붙이거나 관점 수를 늘린 것만으로 충분하다고 보지 않는다.
- 사용자가 선택한 개선은 해당 Owner에 실제 반영하고 내용·연결·필요 실행을 확인한다. 문서 수정이면 원래 사례와 조건이 다른 사례에서 판단을 설명할 수 있는지도 본다.
- 새로운 실제 사용 효과를 아직 확인하지 않았으면 그 범위와 다음 관찰 조건을 남긴다. 무수정 유지도 근거와 남은 한계를 명확히 설명할 수 있으면 유효한 결과다.

스킬·지침 추가량, review 호출 횟수, 제품 테스트 수는 그 자체로 이 목표의 완료 근거가 아니다. 중요한 필수 입력이나 선택이 남으면 부분 완료로 보고한다.
