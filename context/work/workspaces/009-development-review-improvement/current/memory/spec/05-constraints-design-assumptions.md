# 제약·현재 접근·열린 판단

제약: 이 세션의 요청은 기록과 티켓 분리다. 개선 루프 실행·새 기준 채택·스킬 변경은 수행하지 않았다. 다음 실행에서는 improvement-loop의 선택·반영 권한을 따르며 특정 변경에 대한 사용자 선택을 현재 티켓 생성으로 대신하지 않는다. 원문과 과거 기록, 다른 작업의 미커밋 변경을 보존한다.

현재 접근: 최근 정정에서 다시 잡은 요청을 원문으로 확인한 뒤, 대화 흐름과 관련 경험·실물로 범위를 넓힌다. 하나의 선택에 제품 조건·공식 동작·코드 관계·검사 근거가 어떻게 작용했는지 본다. 공식 문서와 설치 버전의 대조도 그 판단에 필요할 때 수행한다. 모든 기술 문서를 전수 조사하는 새 의무가 아니다.

열린 판단: 부족함의 원인이 기존 본문 내용, 읽기·적용, Main의 문제 정의, 리뷰 입력·배치, 테스트의 대표성, 설명 구성 중 어디에 있었는가? 구체적으로 무엇을 유지·삭제·보완해야 하는가? 현재 요약에 남은 아쉬움은 무엇인가? 답을 미리 '새 체크리스트 필요'로 정하지 않는다.
