# 문제·목표·범위

002의 Ticket 01–05와 관련된 활성 `.claude` 자료를 통합해 Project context가 기준 본문을 소유하도록 시험했다. 주제별 API 가이드는 개선됐지만 현재 구현 문서의 실행 일지화, 기존 의미 누락, 날짜의 사실 오류와 기존 읽기 경로의 미연결이 남았다. 날짜·금액·통화 라벨·서버 오류의 제품 선택도 아직 합의되지 않았다.

이 Work는 두 결과를 만든다. 첫째, 미합의의 실제 차이와 사용자가 경험할 결과를 대조해 사용자와 계약을 구체화하고 합의한 내용을 해당 Project Owner와 직접 영향을 받는 기존 문서에 반영한다. 둘째, 작성 기준이 있는데도 문제가 남은 원인을 분석하고 지침을 개선해 다른 세션의 실제 갱신 결과로 효과를 확인한다. Main이 결과물을 직접 다듬은 사실만으로 지침의 효과가 입증되지는 않는다.

포함 범위는 관련 Project 본문, 관리 계약·REFERENCE·읽기/갱신 스킬과 실제 진입 경로다. 제품 원자료는 002 완료 범위와 관련된 코드·schema·test, non-archive `.claude` 자료를 중심으로 선택한다. 002의 Ticket 06 이후나 003의 버그 구현, 제품 문서 전체 개편을 함께 완료하려 하지 않는다.

현재 생성 요청은 다음 세션이 일을 이어받을 Workspace를 만드는 권한이다. 제품 정책은 아직 선택하지 않았고 제품 코드·DB migration의 실행도 시작하지 않았다. 계약 선택 뒤 구현 변경이 필요하면 기존 002·003의 담당 범위와 겹침을 확인해 별도로 배치한다. 문서와 구현의 차이를 남겨 둔 채 구현까지 맞춘 것으로 보고하지 않는다.
