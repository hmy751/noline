# 이 Work를 이어 읽기

먼저 아래 Spec 전체로 목표와 판단 경계를 확인한다. Project 입력에는 아직 검토 중인 본문이 포함되므로 그 문구만으로 제품 선택이나 완료를 이어받지 않는다.

- [문제·목표·범위](spec/01-problem-goal-scope.md)
- [요구 동작과 대표 사례](spec/02-behavior-and-cases.md)
- [개념과 계약](spec/03-concepts-and-contracts.md)
- [품질과 완료 판단](spec/04-quality-and-completion.md)
- [제약·현재 설계·가정](spec/05-constraints-design-assumptions.md)

[Ticket 색인](tickets/index.md)에서 제품 계약 합의와 지침 개선의 실행을 선택한다. [Project 선택](project-context.md)은 각 입력의 역할과 관리 지침을 직접 읽을 시점을, [전체 상태](../state/index.md)는 현재 결과와 첫 행동을 설명한다. 정확한 문구가 필요한 경우에는 [원문 발췌](../../source/user-direction.md)와 [시험 결과 발췌](../../source/trial-excerpts.txt)를 추가한다.
