# 실행할 Ticket

- [01. 미합의된 제품 계약을 구체화하고 반영](01-product-contract-agreements.md): 날짜·금액·통화 라벨·서버 오류의 실제 차이를 확인하고 사용자 선택을 관련 기준 본문에 연결한다.
- [02. Project 작성 지침의 실패 분석과 재시험](02-guidance-failure-analysis-and-retest.md): 기존 지침이 이번 결과의 오류·누락·구성 문제를 걸러내지 못한 이유를 확인하고, 개선한 지침의 실제 적용 결과를 평가한다.

두 실행은 제품 선택과 작성 방법이라는 서로 다른 결과를 맡는다. Ticket 02에서 제품 선택의 정답을 대신 정하지 않고, Ticket 01에서 문서를 직접 수정한 결과를 지침 효과의 증거로 사용하지 않는다. 현재 진행과 다음 행동은 [state](../../state/index.md)에서 확인한다.
