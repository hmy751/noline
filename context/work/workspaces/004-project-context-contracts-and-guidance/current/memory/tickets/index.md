# 실행할 Ticket

- [01. 미합의된 제품 계약을 구체화하고 반영](01-product-contract-agreements.md): 날짜·금액·통화 라벨·서버 오류의 실제 차이를 확인하고 사용자 선택을 관련 기준 본문에 연결한다.
- [02. Project 작성 지침의 실패 분석과 재시험](02-guidance-failure-analysis-and-retest.md): 최소 문구를 반영했고 현재 누락을 보완했다. 다음 독립 Project 갱신에서 재발 여부를 확인한다.

두 실행은 제품 선택과 작성·완료 검증 방식이라는 서로 다른 결과를 맡는다. Ticket 02에서 제품 선택의 정답을 대신 정하지 않고, Ticket 01에서 문서를 직접 수정한 결과만으로 지침 효과를 판단하지 않는다. 현재 진행과 다음 행동은 [state](../../state/index.md)에서 확인한다.
