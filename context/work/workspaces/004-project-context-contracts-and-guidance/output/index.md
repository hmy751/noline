# 현재 산출물

아직 004가 선택·완료한 제품 계약이나 개선된 지침 산출물은 없다. 현재 결과는 Workspace의 초기 작업 정의와 재진입 자료다.

실제 갱신 대상은 Project의 [관리 계약](../../../../project/MAINTENANCE.md)·[REFERENCE](../../../../project/REFERENCE/README.md), [통화](../../../../project/common/currency.md)·[날짜](../../../../project/common/date-and-time.md)·[API](../../../../project/guidance/api-contracts.md) 등 해당 Owner다. 이 링크는 수정 후보의 위치이며 새 결과의 수락·완료 표시가 아니다. 선택한 결과가 생기면 실제 canonical과 확인 범위를 여기 연결하고 본문을 복제하지 않는다.
