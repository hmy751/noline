# 선택한 원자료

- [초기 요청](user-direction.md)과 [이번 Context 우선 재구성](../records/2026-10-30-09-project-context-ticket-reconstruction.md): 처음 목적과 현재 범위 선택을 구별한다.
- [002 기록 색인](../../002-code-readability-refactoring/records/README.md), [산출물 지도](../../002-code-readability-refactoring/output/index.md), [원자료 inventory](../../002-code-readability-refactoring/source/index.md): 실제 수행·결정·코드·검사의 근거를 찾는다.
- [전체 대응 조사](../records/2026-10-30-08-context-coverage-reassessment.md): 실제 축적과 기존 Context의 내용·공백·유지 판단.
- [06 종료](../../002-code-readability-refactoring/records/2026-10-06-03-ticket-06-closure-and-followups.md): 합의된 완료와 보류·후속·미확인 조건.

주제별 시작 기록과 실제 코드는 [각 Ticket](../current/memory/tickets/index.md)에 연결한다. 현재 본문은 [Context 선택](../current/memory/project-context.md)의 Owner에서 읽고 복제하지 않는다. 002 전체 대화 원문을 전수 확인한 것은 아니므로 정확한 선택 범위가 중요한 공백은 해당 원문으로 보완한다. Git의 당시 판본과 현재 코드를 구별한다.
