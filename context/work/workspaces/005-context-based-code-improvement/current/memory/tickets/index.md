# Context 보완 실행 Ticket

다음 개발자가 함께 이해해야 할 관계를 기준으로 묶는다. 각 Ticket은 기록·코드 대조, Context 본문 수정, 필요한 읽기 경로와 내용 확인까지 맡는다. 파일 수나 수정 항목별로 Ticket을 늘리지 않는다.

1. [04 — 앱 실행·세션·데이터 보존](04-app-runtime-context.md): 앱 준비부터 Local 이용과 안전한 종료까지의 현재 책임을 복원한다.
2. [05 — 네트워크·조회·화면 복구](05-network-read-context.md): 실제 관측·정책·조회 실행·내용 표시와 복구의 관계를 설명한다.
3. [06 — 작성·장소·날짜 입력](06-draft-input-context.md): 초안·선택창·저장값과 서비스·날짜 계약의 연결을 보완한다.

04의 인증·종료 계약을 05/06이 참조하고 05의 읽기 제한을 06의 작성 수명과 구별한다. 조사 자체는 필요한 부분부터 진행할 수 있으며 각 Ticket이 맡은 본문·검증을 끝내야 완료한다. 이미 반영된 결과와 배치는 [범위 지도](../review-scope.md)에 있다. 개인 판단·협업·스킬 개선은 후순위이며 현재 실행 목록에 넣지 않는다.

- [이전 03 — 인증 책임](03-auth-session-responsibilities.md): 코드 구조 재검토 계획은 대체됐다. 관련 Context는 04가 맡는다.
