# 문제·목표·범위

02에서 수행한 설계 선택과 실제 결과를 당시 기록·현재 코드·새 Personal·Project Context로 재검토한다. 사용자가 얻을 결과는 무엇을 유지하고 무엇을 개선할지 근거 있는 판단과, 채택한 개선이 구현·검증된 코드다. 과거 승인이나 새 기준의 존재만으로 현재 선택의 타당성을 결정하지 않는다.

검토 대상은 02의 01–06 결과와 07–18에 실제 반영된 선행 조각이다. 기능 이름별로 수정 대상을 미리 만들지 않고, 당시 해결하려던 문제·선택 과정·연결된 코드 결과를 함께 설명할 수 있는 단위로 묶는다.

초기 실행은 저장 용량 Hook의 책임 분리, 일정·경비 조회 조합의 공통화, 인증·세션 책임 재배치다. 세 단위는 당시 선택과 결과의 근거가 남아 있어 정한 시작 범위다. 나머지는 review-scope에 미검토로 유지하고 실제 결과를 복원하며 다음 단위를 정한다.

기록상 미완료 작업은 기존 결과의 한계를 판단하는 입력으로 사용한다. 02의 미완료 전체나 003의 결함 전체를 인수하지 않는다. 기존 결과를 이해·개선하는 데 필요한 소비자와 연결은 함께 확인하며, 제품 정책·기존 보류·공개 계약을 바꾸는 선택은 권한과 영향을 따로 판단한다.
