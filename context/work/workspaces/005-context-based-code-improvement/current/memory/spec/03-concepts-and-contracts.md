# 근거와 Context의 책임

당시 기록·결정은 채택한 의미·선택 이유·보류의 근거이며, 현재 코드는 구현·지원 사실의 근거다. 중간안·원복안을 현재 계약으로 옮기지 않고 구현만으로 새 제품 요구를 채택하지 않는다. 정확한 선택의 범위가 중요하면 기록에 보존된 원문과 필요한 원자료를 확인한다.

Project는 여러 작업에서 다시 필요한 제품 의미·현재 관계·개발 계약을 소유한다. 기존 상세 Owner가 남아 있는 주제는 그 본문을 보완한다. 새 주제가 필요하면 Project의 내용 구성 기준에 따라 배치하고, 다른 주제의 권위 이동이나 전체 폴더 재편으로 넓히지 않는다. Work는 이번 수행·검증·후보와 진행을 보존한다.

한 Ticket은 함께 이해해야 할 Context 결과를 맡는다. Ticket 수와 생성할 파일 수는 일치할 필요가 없다. 같은 계약의 상세를 여러 문서가 따로 소유하지 않도록 본문 Owner를 정하고 필요한 전제·연결만 다른 곳에 둔다.

Personal 판단은 기존 참고 관점으로 사용할 수 있지만 이번에 고칠 산출물은 아니다. 개인 기준·협업 방식의 재검토는 후순위다. 002의 역사 자료와 사용자 보류는 유지하고 005에서 현재 결과를 독립적으로 구성한다.
