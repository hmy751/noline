## 릴리스 노트

사용자 지적대로 직전 초안(11-02)은 build 13의 동기화 수정을 담지 않았다. 빌드 11 이후 앱 쪽 `feat`·`fix` 커밋 27건을 다시 훑었다. 그중 다음 셋에 해당하는 것만 골랐다.

- 화면에서 달라진 것
- 데이터가 사라지거나 막히던 문제가 고쳐진 것
- 사용자가 직접 해야 할 일이 생긴 것

저장한 문구는 다음과 같다.

```text
여행 도시의 시간으로 날짜와 시간을 보여 줘요.

• 여행을 만들거나 수정할 때 도시의 시간대가 함께 저장돼요.
• 일정·경비의 날짜와 시간, 홈 화면의 여행 날짜가 여행 도시 기준으로 맞춰져요.
• 이전에 만든 여행은 편집 화면에서 도시 시간대를 한 번 확인하면 적용돼요.

날짜·시간 선택이 편해졌어요.

• 시간 선택 휠이 가운데 줄에 맞춰 읽기 쉬워졌어요.
• 선택창이 지금 입력된 날짜와 시간에서 열려요.

연결이 불안정할 때도 기록이 더 안전해졌어요.

• 전송 중에 연결이 끊기거나 앱이 종료돼도, 앱을 다시 열거나 연결이 돌아오면 남은 기록을 이어서 보내요.
• 한 기록의 전송 실패 때문에 이후 기록이 서버에 올라가지 않던 문제를 고쳤어요.
• 앱으로 돌아오면 연결 상태를 다시 확인하고, 연결이 제한된 동안 작성 중인 입력을 지켜요.
• 로그아웃이나 계정 전환 중에도 기기에 저장된 기록을 지켜요.

그 밖에 접근성과 안정성을 개선했어요.
```

직전 초안과 다른 선택:
- **전송 시점:** "앱을 다시 열거나 연결이 돌아오면"으로 적었다. 저장 즉시 서버로 간다고 읽히지 않게 하려는 것이다. 근거는 [관찰 기록](2026-11-02-01-simulator-sync-block-observation.md#릴리스-노트에-준-영향)이다.
- **이전 여행의 시간대 확인:** 사용자가 직접 해야 할 일로 넣었다. 11-02 시뮬레이터에서 기존 여행 카드의 "시간대 확인 필요"와 편집 화면의 확인 버튼을 봤다.
- **한 줄로 묶은 것:** 홈 요약과 목록 복구의 책임 정리, 여행 생성 경로 정리, 서버 소유권 확인 강화, 서버의 재전송 처리는 "그 밖에" 한 줄과 "막히던 문제를 고쳤어요"에 묶었다.
- **"막히던 문제" 줄:** 1.0.1에도 있던 문제를 고쳤다고 밝히는 셈이다. 빼도 뜻이 통한다고 사용자에게 알렸고, 사용자는 그대로 승인했다.

## 심사 제출 (같은 날 23:30)

사용자가 TestFlight 실기기 확인 없이 제출하기로 했다. 지시 원문은 다음과 같다.
- "심사 그냥 하면 안돼?"
- 이전 설정을 보여 드린 뒤 "그냥 하자"
- 연령 등급 답안을 보여 드린 뒤 "Answer and submit"

- **이전 방식과 같게 둔 설정:** 1.0.1도 자동 출시였고, 1.1.0 초안도 그 설정을 이어받았다. 다음을 그대로 두었다.
  - 심사 통과 시 자동 출시
  - 모든 사용자에게 즉시 업데이트 출시
  - 기존 평가 유지
- **심사 메모:** 데모 계정 없이 본인 Google·Apple 계정으로 로그인하라는 안내다. 1.0.1과 같은 메모다.
- **처음 제출을 막은 것:** "필수 연령 등급 관련 질문에 답변해야 합니다." Apple이 연령 등급 설문에 새로 추가한 두 문항이 비어 있었다.
  - 소셜 미디어
  - 13세 미만 사용자의 소셜 미디어 비활성화
- **연령 등급 답:**
  - 비어 있던 두 문항을 "아니요"로 답했다.
  - 앱 코드에서 공유·채팅·광고·웹 화면 코드를 찾지 못했다. 외부 링크는 Google 지도 길 안내 하나(`apps/client/src/shared/lib/external-map.ts`)뿐이다.
  - 나머지 2~6단계는 기존 답(모두 없음·아니요)을 그대로 두었다.
  - 계산된 등급은 4+로 유지됐고, 재정의는 "해당 없음"이다.
  - 앱 정보 페이지를 저장한 뒤에도 4+(대한민국 "전체")로 보였다.
- **제출:**
  - "심사에 추가"를 누르자 제출 초안에 "iOS 앱 1.1.0 (13)" 한 항목이 담겼다.
  - "심사를 위해 제출" 뒤 "1개의 항목 제출됨, 심사에는 최대 48시간"이 표시됐다.
  - 페이지를 새로 불러오자 상태가 **심사 대기 중**이었다.
- **한국 법 연락처 정보:** 제출을 막지 않았다.

## 확인하지 않은 것

- **운영의 재전송 응답:** 운영 데이터를 바꾸지 않고는 확인할 수 없어 호출하지 않았다. 서버 테스트만이 근거다.
- **build 13의 실기기 동작:** TestFlight에서 로그인, 여행 목록, 일정 저장 뒤 동기화를 확인하지 않은 채 제출했다. 자동 출시라 심사가 통과하면 바로 공개된다.
