# 완료 판단

아래가 모두 실제로 확인되면 이 Work를 완료로 본다. 버전을 올렸다거나 빌드가 성공했다는 사실만으로 확인을 대신하지 않는다. 버전 논의 뒤 대상 SDK에 맞춰 구체화한다.

1. **Apple 요건:** 업그레이드한 앱이 iOS 27 SDK(Xcode 27 이미지)로 빌드되어 App Store Connect 업로드와 심사를 통과한다. 업로드 메일에 최소 iOS·SDK 경고가 없다.
2. **iOS 27에서 시작:** 그 빌드가 iOS 27 기기 또는 시뮬레이터에서 정상 시작한다(UIScene).
3. **기존 사용자 업데이트:** 이전 스토어 빌드(SDK 51)에 데이터가 있는 상태에서 새 빌드로 업데이트해도 로그인·기기 DB·미전송 큐·오프라인 지도가 유지된다.
4. **오프라인 약속:** 네트워크 없이 앱이 열리고 활성 여행을 조회·변경할 수 있다.
5. **위험 영역:** [동작과 사례](02-behavior-and-cases.md)의 깨지기 쉬운 영역을 각각 실제 화면이나 검사로 확인한다.
6. **의존성 정합:** `npx expo install --check`가 대상 SDK 기준으로 통과하거나, 남은 차이마다 이유가 기록돼 있다.
7. **OTA:** 011의 expo-updates가 새 빌드에서 업데이트 받기·업데이트를 기다리지 않는 시작·롤백을 다시 통과한다. 새 빌드의 fingerprint가 SDK 51 빌드와 달라 이전 업데이트를 받지 않는다.
8. **기존 검사:** client lint·test·typecheck가 업그레이드 전과 같은 수준 이상이다(업그레이드 전 기준선을 먼저 기록한다).
9. **재발 방지:** 설치·확인 방법이 다음 작업자가 찾을 위치에 남아 있다.

실기기·시뮬레이터 중 무엇으로 확인했는지는 각 확인의 기록에 남긴다.
