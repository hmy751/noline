- [2026-11-16 — expo-updates 논의와 Work를 만든 경위](2026-11-16-01-discussion-and-work-creation.md): 1.1.3 배포가 논의를 부른 맥락, 각 추천(fingerprint, 시작 시 기다리지 않음, DB·서버 계약·환경값 규칙, iOS 15 동반)의 이유, 넣지 않은 것, hook과 Project 반영을 열린 판단으로 둔 이유. 추천을 바꾸거나 규칙을 확정할 때 읽는다.
- [2026-11-16 — 착수 전 파악과 SDK 업그레이드를 012로 분리한 경위](2026-11-16-02-scoping-check-and-sdk-split.md): "파악만" 정정으로 되돌린 설치, 파악에서 확인한 것(SDK 51 버전 조합, fingerprint 지원, dev-client 충돌, `expo install --check`의 어긋남 10개), 과거 업그레이드 사례와 Apple 2027년 4월 조건 분석, 012로 나눈 이유와 비용, 011에 남긴 조정. 1단계 판단 지점에서 011을 계속할지 012에 합칠지 다시 볼 때, 또는 dev-client 정렬의 근거가 필요할 때 읽는다.
