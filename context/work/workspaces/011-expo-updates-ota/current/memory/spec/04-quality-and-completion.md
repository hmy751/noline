# 완료 판단

아래가 모두 실제로 확인되면 이 Work를 완료로 본다. 설정을 넣었다는 사실만으로 확인을 대신하지 않는다.

1. **업데이트 받기:** preview 빌드가 preview 채널의 업데이트를 받아 다음 실행에 적용한다.
2. **오프라인 시작:** 네트워크가 없는 상태에서도 앱이 업데이트를 기다리지 않고 바로 열린다. 이미 받아 둔 업데이트가 있을 때도 같다.
3. **롤백:** `eas update:rollback`(또는 이전 업데이트 재발행)으로 되돌리면 기기가 그 번들로 돌아간다.
4. **runtime 분리:** 네이티브 설정을 바꾼 빌드와 이전 빌드의 fingerprint가 다르고, 이전 빌드는 새 runtime의 업데이트를 받지 않는다.
5. **발행 번들의 내용:** 발행한 번들의 `EXPO_PUBLIC_*` 값이 production 값이다. Sentry에서 소스맵으로 원래 코드 위치가 보인다.
6. **방지 장치:** 위험한 변경(Spec 02의 "불가"·조건부 행)이 포함된 발행을 실제로 막는다. 막히는 경우와 통과하는 경우를 각각 한 번 이상 실행해 확인한다.
7. **스토어 빌드:** 1.1.4가 iOS 최소 버전 15.0으로 빌드되고, 업로드 메일에 ITMS-90068이 다시 오지 않는다. 그 빌드가 심사를 통과한다.
8. **Project 반영:** OTA 가능·불가 기준과 발행 절차가 Project context의 알맞은 Owner에 반영되어 있다. 이 Work가 끝난 뒤에도 다음 작업자가 그 기준을 찾을 수 있다.

실기기 검증 범위(시뮬레이터만인지, 실기기인지)는 각 확인의 기록에 남긴다.
