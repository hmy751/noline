# 경험 학습보다 전체 개선 목적을 드러낸 이름

2026-10-28. 사용자는 `learning`이 배우는 데 집중한 이름으로 보인다며 전체 성격을 담는 이름을 요청했다. Main은 `improvement-loop`를 추천했고 사용자가 수용했다.

> 근데 왜 learning이야? 너무 배우는거에 집중하는것 같아서 전체 성격을 고려한 네이밍은 없을까?
>
> 그래 그걸로 네이밍하고 다시 기록이나 이런거 한번 점검하고
> 검증자랑 개선리뷰 돌려봐 개선은 더 잘 하기위한 개선을 묻는 리뷰

이 루프는 대화·경험을 입력으로 사용하되 현재 본문·기준·구조·협업·도구를 살피고 좋은 방법 구체화·새 가능성·삭제/통합·유지까지 판단해 선택한 개선을 반영한다. 그래서 이름을 [improvement-loop](../../SKILL.md), 제목을 ‘작업 체계를 살펴 더 나은 선택을 반영한다’로 바꿨다. 범위를 새로 넓힌 것이 아니라 기존 합의의 전체 목적을 드러낸 것이다.

초기 작성 기록의 `learning-loop`는 당시 이름이다. 현재 호출·본문·연결은 새 이름을 사용한다. 이 명칭 변경으로 자동 반복·별도 리뷰어가 필수가 되지 않는다.
