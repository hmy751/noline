# 스킬 본문 관리 정책의 형성 자료

[SKILLS-CONTENT-POLICY](../../SKILLS-CONTENT-POLICY.md)가 만들어진 목적·선택 이유·당시 발화와 확인 범위를 보존한다. 현재 작성·갱신 기준은 정책 본문에서 읽고, 그 이유를 이해하거나 바꿀 때 여기에서 필요한 자료를 고른다.

| 확인할 질문 | 읽을 자료 |
| --- | --- |
| 기존 context 정책을 스킬에 어떻게 이어받았나 | [형성 맥락](context.md) |
| 왜 skills 안에 정책을 두고 대문자 이름을 썼나 | [작성 결정](records/2026-10-21-initial-policy.md), [사용자 발화](evidence.md) |
| 수정안 채택 뒤 후보·과거 판본을 어떻게 구별하나 | [형성 맥락](context.md#내용-분할과-판본-보존을-구별한-이유), [보완 기록](records/2026-10-22-revision-lifecycle.md), [발화 근거](evidence.md#수정안-채택-뒤-중복-판본에-대한-정정) |
| 실제 어디까지 적용하고 확인했나 | [작성 결정의 적용 범위](records/2026-10-21-initial-policy.md#적용-범위) |

과거 제안은 현재 채택·실행 완료와 다를 수 있다. 전체 스킬의 적용 상태나 운영 설치를 이 자료만으로 추정하지 않는다.
