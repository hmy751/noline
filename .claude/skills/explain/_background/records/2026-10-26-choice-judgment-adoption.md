# 지원 목표와 실제 사용처를 함께 비교하는 선택 판단

2026-10-26. 사용자가 배경을 종합한 방향으로 본체·상세·형성 자료를 반영하고 2번·4번을 GPT-6-sol medium으로 다시 수행하도록 요청했다. [근거](../evidence.md#선택-질문과-배경-종합-뒤의-보완--2026-10-26)는 실제 발화·최초 응답·Main의 정정과 실험 위치를 보존한다.

기존에도 요구·사용처·대안 비용의 비교가 있었다. 이번에는 일부 적용의 충분성과 명시된 지원 목표를 구별하고, 같은 사용 조건에서 현재안과 대안이 필요한 결과를 만드는지 대조하도록 해당 문단을 교체했다. 앞선 AI 제안·채택된 계약·현재 구현을 구별하면서 과거 제안과의 일치나 현재 구현의 존재만으로 결론을 닫지 않는다.

작성 상세의 여행 복구 사례는 유지하고 마지막 반환 항목 일반 예시를 정보·판단·실행 필요와 대안 부담의 비교로 확장했다. 특정 반환 필드·고정 대안 수·모든 사용처 조사나 새 설계 검토 역할을 요구하지 않는다. 상세 읽기 연결을 선택 조건 가까이에 옮겼지만 열람이 판단 품질을 보장한다는 주장은 하지 않는다.

기존 전체·부분 설명, 실제 코드 대응, 앞선 말의 원뜻·정정, 전후 비교, 동작 보존과 개선 근거의 구별, 현재성·권한 조건은 유지한다. 추가 확인의 수행은 development가 소유하며 explain에 검사 절차를 복제하지 않았다. `skill-creator`의 필요한 판단만 구체화하기와 로컬 본문 관리 정책의 본체·상세·형성 근거 구별을 적용했다.

이 기록은 반영 선택이다. 기존 의미 대조·정적 검사와 실제 응답 효과는 구별하며, 실행 결과와 평가는 Workspace014 `records/2026-10-26-ticket04-02-choice-investigation-adoption.md`, `records/experiments/explain-choice-investigation-60medium-revised-2026-10-26/`에서 찾는다. 새 응답이 마음에 들지 않는다는 이유로 다시 생성하지 않는다.

후속 최초 수행에서는 같은 GPT-6-sol medium이 작성 상세·폼 발췌를 읽고, 캐시 표시와 실제 조회 제한이 갈리는 조건을 추천 근거로 들었다. 과거 제안과의 일관성만으로 닫던 답보다 구체적이지만, 전체 접근 정보 공개의 부담과 더 좁은 대안은 이후로 미뤘다. 원응답은 보존하고 실행 지침을 재수정하지 않았다. 같은 장면 각1회의 부분 개선이며 일반 효과나 선택 판단의 완전 충족으로 보지 않는다.
