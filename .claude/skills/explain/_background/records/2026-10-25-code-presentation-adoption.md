## 채택한 변경

- 본체는 코드의 역할·구조·흐름을 묻는 요청에서 실제 코드를 동반하고, 문법 설명의 깊이는 별도로 정한다. 첫 결과의 핵심 코드 주장에도 적용하되 코드가 언급된 모든 판단 질문을 코드 읽기 과제로 만들지 않는다.
- 실제 역할·협력이 드러나는 처리 단위를 고르고 조건과 후속 동작·값 저장과 사용을 함께 보여 준다. 작은 함수 전체를 허용하며, 발췌·생략이 조건이나 반환 의미를 바꾸지 않도록 한다.
- 핵심과 보조의 비중, 같은 기준의 대비, 코드와 해설의 인접 배치, 조건부 도식과 필요한 재표현을 구체화했다. 내용을 줄이거나 표·코드 블록의 개수를 강제하지 않는다.
- 기존 인증 예시를 실제 try/catch와 작업/현재 세션의 값 대비로, 동기화를 첫/뒤 호출의 대비로, 여행을 실제 작업 제공/실행 선택의 역할 대응으로 바꿨다. 보고서의 조사 책임과 앞선 발화의 복구 상세는 유지했다.
- 마무리에서는 코드의 존재보다 제시 코드와 해설로 핵심 관계를 따라갈 수 있는지 확인한다.03·04 답을 실행 상세에 새 정답 예시로 추가하지 않았다.
