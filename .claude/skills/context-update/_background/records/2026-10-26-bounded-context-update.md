# 2026-10-26 — 지정된 지속 본문의 반영 과업을 적용

[context-update](../../SKILL.md)를 prototype에 추가했다. 기존 Project 반영 방법을 Personal·Project의 각 관리 계약에 따라 재사용하며, 읽기만 요청과 Work 상태 유지·새 Work 생성은 이 과업의 범위에서 제외했다.

후속 합의에 따라 담당자의 제안과 Main의 전체 검토·반영을 연결했다. Project를 고치기 전에 지속할 공통 의미가 달라졌는지 선별하고, 실제 반영한 본문과 필요한 읽기 경로·근거를 확인한다. 문서 반영 완료와 제품 요구 충족·전체 완료를 구별하며 남은 영향은 Main에게 돌려준다.

이미 유효한 읽기와 근거를 사용하고 별도 제안서·전체 재독·매번 새 승인을 강제하지 않는다. 경험 개선에서 채택한 본문 변경에도 같은 방법을 쓸 수 있지만 일상 갱신을 그 단계까지 미루지 않는다. [형성 이유](../context.md)와 [직접 근거](../evidence.md)에 당시 후보·정정·열린 범위를 남겼다.

이 기록은 실행 본문과 관리 연결의 적용이다. 실제 운영 설치·host 발견·다른 저장소 배포·장기 효과의 확인으로 확대하지 않는다.
