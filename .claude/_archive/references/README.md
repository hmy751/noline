# Archived Noline References

이 디렉터리는 현재 구현 정책으로 쓰지 않는 과거 reference 자료를 보존한다. PRD, wireframe, 이미지 기술 참고처럼 제품/구현 초기에 유용했지만 지금은 active startup path에서 제외된 자료다.

## 현재 자료

| 파일 | 역할 | 읽는 방식 |
| --- | --- | --- |
| [prd.md](prd.md) | 초기 제품 요구사항과 가치 제안 | 과거 제품 의도를 확인할 때만 읽는다. 현재 구현 정책과 충돌하면 active guide와 코드를 우선한다. |
| [wireframe.md](wireframe.md) | 초기 화면 구조와 UX 스케치 | 오래된 UI 의도를 추적할 때만 읽는다. 현재 UI 구현과 충돌하면 코드와 workspace guide를 우선한다. |
| [react-native-image-guide.md](react-native-image-guide.md) | 예전 React Native 이미지 기술 참고 | 기술 history로만 읽는다. active 정책으로 승격하지 않는다. |

## 경계

- 상세 구현 지침은 [context](../../context/README.md), [rules](../../rules/README.md), [runbooks](../../runbooks/README.md)가 소유한다.
- 오래된 구현 추적표와 테스트 시나리오는 [../implementation](../implementation/)에 보존한다.
- 이 디렉터리의 파일은 현재 정책처럼 읽지 않는다.
